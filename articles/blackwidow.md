# ブラック・ウィドウの家族は本物？タスクマスターの正体（ネタバレあり）

※『ブラック・ウィドウ』の結末と、エンドクレジット後の場面まで書いています。『シビル・ウォー』『エンドゲーム』の内容にも少し触れます。『サンダーボルツ*』の結末には触れません。

ナターシャ、エレーナ、アレクセイ、メリーナの4人に、血のつながりはありません。レッドルームの任務で、オハイオで3年間、家族を演じていた4人です。食卓では、家族は3年だけの計算された偽装で、本物ではなかった、という言葉が出ます。エレーナは、自分には本物だったと返します。終盤ではナターシャも、自分にも本物だったと言います。

タスクマスターの正体は、レッドルームの支配者ドレイコフの娘、アントニア・ドレイコフです。ナターシャは過去に、ブダペストでドレイコフのいたビルを爆破し、娘も死んだと思っていました。いつの話かは、『シビル・ウォー』のあとです。

## 家族の4人は誰か

| 人物 | 偽装家族の役 | 実際の姿 |
|---|---|---|
| ナターシャ・ロマノフ（スカーレット・ヨハンソン） | 姉 | レッドルームで育った暗殺者。のちにS.H.I.E.L.D.のエージェントになり、アベンジャーズの創立メンバーになる |
| エレーナ・ベロワ（フローレンス・ピュー） | 妹 | レッドルームのウィドウ。ナターシャを姉として慕い、アレクセイとメリーナも本当の家族のように想っていた |
| アレクセイ・ショスタコフ／レッド・ガーディアン（デヴィッド・ハーバー） | 父 | ソ連のスーパーソルジャー。キャプテン・アメリカに対抗して生まれた。任務のあとドレイコフに投獄された |
| メリーナ・ヴォストコフ（レイチェル・ワイズ） | 母 | ナターシャより上の世代のウィドウで、科学者。レッドルームの訓練を4回受けさせられた、と自分で話す。現在は農場で豚を使って洗脳技術を研究している |

## 偽装家族は、いつからいつまでだったか

物語は、少女のナターシャとエレーナが、オハイオで父母と夕食をとる場面から始まります。4人は、レッドルームの任務のために、仲のよい家族を3年間演じていました。1995年に任務を終えると、4人はS.H.I.E.L.D.の追っ手を振り切ってキューバへ逃げ込み、この日に偽装家族はバラバラになります。キューバの滑走路にはドレイコフが待っていて、ナターシャとエレーナは、父母役の2人から引き離され、レッドルームへ連れて行かれます。

大人になって再会した4人は、食卓で、家族とは何だったのかを話します。

| 誰の言葉か | 内容 |
|---|---|
| 食卓での話 | 家族は3年だけの計算された偽装だった |
| ナターシャ | 本物じゃなかった。どうでもいい |
| アレクセイ | 潜入工作員にしては、親としてはよくやった |
| メリーナ | 命令があって、役を完璧に演じた |
| エレーナ | 自分には本物だった。メリーナは本当の母だった |

終盤、ナターシャはエレーナに、自分にも本物だったと返します。メイソンとの会話では、自分には家族がいないと思っていたが、実際は2つあった、と話します。2つ目は、アベンジャーズです。

## レッドルームとウィドウ

レッドルームは、適性のある少女を集めて洗脳と訓練を施し、ウィドウとして操る組織です。空に浮かぶ施設で、支配者はドレイコフ（レイ・ウィンストン）です。ナターシャは、レッドルームはとうになくなったと思っていました。エレーナは、まだ動いていると話します。

ウィドウには、ドレイコフのフェロモンを嗅ぐと、本人に暴力を向けられなくなる仕組み（フェロモンによるロック）があります。エレーナがナターシャに送ったのは、このマインドコントロールを解く、解毒用の合成ガス（レッドダスト）です。

ナターシャはウィドウたちを解放し、世界中のウィドウの情報を手に入れます。エレーナはドレイコフを殺し、レッドルームは崩壊します。ナターシャはエレーナに合成ガスを預け、残るウィドウを救うよう言います。

## タスクマスターの正体は、ドレイコフの娘アントニア

タスクマスター（オルガ・キュリレンコ）は、相手の動きを見るだけでコピーして戦います。ナターシャの動きもコピーするため、戦闘中、ナターシャはエレーナに、鏡と戦っているようだと話します。

ナターシャは過去に、ブダペストで、クリント・バートンとともに、ドレイコフと娘がいたビルを爆破しました。娘は死にませんでした。ドレイコフは、爆発で娘が死にかけたので首の後ろにチップを入れた、と明かします。戦いのあと、ナターシャが解毒の合成ガスを使い、アントニアはドレイコフから解放されます。

## いつの話か

『シビル・ウォー』でアベンジャーズが分裂したあとの話です。ナターシャはソコヴィア協定に違反した者として、サディアス・ロスをはじめ世界中から追われています。

本編のあと2週間たち、ナターシャはメイソンからクインジェットを受け取り、拘束されたままのアベンジャーズを解放しに飛び立ちます。公開順では『ファー・フロム・ホーム』の次の作品ですが、MCUの時系列では、『シビル・ウォー』と『ブラックパンサー』の間に入ります。

## エンドクレジット後

『エンドゲーム』のあとの場面です。ナターシャの墓をエレーナが訪れると、ヴァレンティーナ（ヴァル、ジュリア・ルイス＝ドレイファス）が接触します。ヴァルは、ナターシャの死にクリント・バートンが関わっていると告げ、次の標的として示します。

エレーナは、ドラマ『ホークアイ』（2021年）にも出ています。

## 『サンダーボルツ*』にも出る人

エレーナ、アレクセイ、タスクマスター、ヴァルは、『サンダーボルツ*』にも出ます。人物の紹介は、こちらの記事にあります。
