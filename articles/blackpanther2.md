# ワカンダ・フォーエバーの最後の子供は誰？ラストの場面（ネタバレあり）

※『ブラックパンサー／ワカンダ・フォーエバー』の結末とミッドクレジットまで書いています。『ブラックパンサー』（1作目）の結末にも触れます。

ラストの少年は、ティ・チャラとナキアの息子です。名前は2つあって、トゥーサンはハイチでの名前、ワカンダでの名はティ・チャラです。ミッドクレジットで、ナキアがシュリに、息子のトゥーサンだと紹介します。

ナキアは、ティ・チャラと取り決めて、息子をハイチで育てていました。ティ・チャラは、冒頭で病気のために亡くなっています。

[[IMG:blackpanther2-flow.png|ティ・チャラの死からミッドクレジットまでの流れ]]

## ミッドクレジットの人物

## ミッドクレジットの場面を、台詞の順に

ネイモアとの決着のあと、ワカンダの戦いの後始末が描かれ、シュリがハイチのナキアを訪ねます。

| 順 | 描かれること |
|---|---|
| 1 | シュリは、自分だけでやらせてほしいと言い、喪服を燃やして、ティ・チャラの喪に服す（序盤で、ラモンダが自分の喪服を燃やしてシュリにも勧めたが、シュリは断っていた） |
| 2 | ミッドクレジット。ナキアが少年を連れてきて、シュリに、息子のトゥーサンだと紹介する。この人があなたの叔母のシュリ、と少年に言う |
| 3 | ナキアは、少年がここで育つほうがよいと決めた、王位の重圧から離れて、と話す |
| 4 | ナキアは、ティ・チャラは自分の死に備えていたが、時がまだ来ていないと考えて、葬儀には来ないよう言った、とも話す |
| 5 | シュリが、母ラモンダは少年に会ったかと聞き、ナキアは会ったと答える |
| 6 | 少年は、トゥーサンはハイチでの名前で、本名はティ・チャラ王子、ティ・チャラ王の息子だと自分で言う |

## ナキアはなぜハイチにいる？

ナキアがハイチにいるのは、息子を王位の重圧から離れたところで育てるためで、ティ・チャラと2人で決めたことだと、ミッドクレジットでナキア自身が話します。ハイチでは教師として暮らしていて、子どもたちが壁に絵を描き、魚に餌をやり、食べ物を育てる学校の場面が描かれます。

ラモンダはハイチのナキアを訪ね、葬儀に来なかったことに触れます。ナキアは、葬儀が終わりになるのが怖かった、と答えます。ラモンダは、シュリの救出もナキアに頼みます。

序盤には、ラモンダがシュリに、兄について話すことがあると言いかける場面もあります。その直後にネイモアが現れ、話は中断します。続きは、この場面では語られません。

## ネイモアとはどう決着した？

最後は、シュリがネイモアに降伏を求め、ネイモアが受け入れて戦いが終わります。

ネイモアは、海底王国タロカンの王です。足首に翼があり、空を飛びます。ネイモアの攻撃でラモンダが亡くなり、シュリは反撃を決めます。

| 順 | 描かれること |
|---|---|
| 1 | ネイモアがワカンダを襲い、ラモンダはリリ・ウィリアムズを助けて溺れて亡くなる |
| 2 | シュリは、ハート型ハーブを再現して飲み、先祖の世界へ行く。会うのは、1作目の敵だったキルモンガーで、ティ・チャラには会えない |
| 3 | シュリは新しいブラックパンサーとなり、部族に認められる。母の死の報復として、ネイモアへの反撃を決める（エムバクは和平を勧める） |
| 4 | 船でネイモアをおびき出し、砂漠の海岸に墜落させて戦う。シュリが優勢になったところで、ラモンダの幻を見て、降伏を求める |
| 5 | シュリは、降伏すればワカンダが海を守る、秘密も守る、とネイモアに告げる。ネイモアは受け入れ、戦いは終わる |
| 6 | ネイモアは、ワカンダと手を組むことがタロカンのためになると考える |
