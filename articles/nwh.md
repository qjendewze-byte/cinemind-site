# ノー・ウェイ・ホームのラスト、ピーターはなぜ記憶を消した？（ネタバレあり）

※『スパイダーマン：ノー・ウェイ・ホーム』の結末と、エンドクレジットの2つの場面まで書いています。『ファー・フロム・ホーム』の結末にも触れます。続編『ブランド・ニュー・デイ』の中身は書いていません。

ラストで、ピーター・パーカーは、ピーターを知るすべての人の記憶から消えます。ピーター自身がストレンジに頼んだ呪文で、別の世界の人物がこちらに来るのはピーターのせいだと言われたピーターが、自分を知る人がいなくなればよいと考えたためです。MJとネッドはMITに進みますが、ピーターのことを覚えていません。ピーターは正体を明かさずに去り、1人の部屋で手作りのスーツを着て、スパイダーマンとして街に出ます。記憶が戻るかどうかは、本編では描かれません。

## なぜ記憶を消したのか（経緯）

『ファー・フロム・ホーム』のミッドクレジットで、ピーターの正体と、ミステリオ殺害の容疑が世間に知られます。本作はその直後から始まります。

| 順 | 出来事 |
|---|---|
| 1 | ピーターは殺人容疑で取り調べを受けるが、弁護士のマット・マードック（チャーリー・コックス。ドラマ『デアデビル』の主人公）が容疑を晴らす |
| 2 | ピーター、MJ、ネッドの3人とも、MITに不合格になる |
| 3 | ピーターはストレンジに、自分の正体を全員の記憶から消す呪文を頼む |
| 4 | 詠唱の途中でピーターが条件を足して割り込み、呪文が壊れる。ピーターの正体を知っている、別の世界の人物が次々と呼び寄せられる |
| 5 | ゴブリンの襲撃で、メイおばさんが亡くなる |
| 6 | 自由の女神での戦いで、3人のピーターが敵を治療し、善人に戻す。ゴブリンが呪文を解き放ち、ピーターの正体を知る別の世界の人々がさらに引き寄せられる |
| 7 | ピーターは、全員の記憶から自分を消す呪文を頼む。MJとネッドに、必ず会いに行って全部説明すると約束する。呪文が効き、別の世界から来た人物は全員元の世界へ戻る |

別の世界の人々は、ピーター・パーカーを知っているから引き寄せられていました。そこでピーターは、ピーター・パーカーという人物そのものを、全員の記憶から消すようストレンジに頼みます。1回目と2回目の呪文は、消すものが違います。

[[IMG:nwh-spells.png|ノー・ウェイ・ホームの1回目と2回目の呪文の比較]]

1回目は、ピーターがスパイダーマンだと知っている人に、そのことを忘れてもらうための呪文でした。ピーターが詠唱の途中で条件を足したために壊れ、別の世界でピーターの正体を知る人まで呼び寄せてしまいます。2回目は、ピーター・パーカーという人物そのものを、知る人全員の記憶から消す呪文です。ストレンジは、呪文が効くとピーターを知る人は全員が記憶を失い、存在しなかったようになる、と説明します。この呪文が効いて、別の世界から来た人物は全員元の世界へ戻りました。

## ラストの場面（ドーナツ店と最後のスーツ）

| 場面 | 描かれること |
|---|---|
| 数週間後、ドーナツ店 | ニュースで、自由の女神での騒動から数週間たったと伝えられる。店員のMJはピーターを覚えていない。ピーターはコーヒーを頼み、MITが楽しみだというMJの話を聞く。MJの額の傷に目をやるが、正体を明かさずに店を出る |
| メイの墓 | ピーターを覚えていないハッピーと話す。ハッピーは、少し前に大切な友人を亡くしたと話し、ピーターは、メイが助けた人たちがその思いを受け継ぐ、という趣旨のことを言う |
| 最後 | ピーターは、物のほとんどない部屋に1人で移り、自分で縫った新しいスーツを着て、雪のニューヨークへ窓から出ていく |

必ず会いに行って全部説明する、という約束は、店では果たされません。MJとネッドがMITに進んだことは、この場面で分かります。

ネッドとMJが記憶を取り戻すかどうかは、本編では描かれません。「記憶のかけらが残っている」というのは観た人の解釈で、作中で説明される場面はありません。

続編の公式あらすじは、この決断から4年がたち、大人になったピーターがスパイダーマンとして戦い続けている、と書いています。
