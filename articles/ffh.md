# ファー・フロム・ホームのミステリオの正体と目的は？（ネタバレあり）

※『スパイダーマン：ファー・フロム・ホーム』の結末と、ミッドクレジット・ポストクレジットの場面まで書いています。『アベンジャーズ／エンドゲーム』の結末にも触れます。『ノー・ウェイ・ホーム』は、どこから話が始まるかだけ書いています。

『スパイダーマン：ファー・フロム・ホーム』（2019）のミステリオ（クエンティン・ベック）は、トニー・スタークに解雇された、元スターク・インダストリーズの技術者です。別の地球から来た兵士だという話も、4体のエレメンタルズも、作り話と幻影でした。目的は、ピーターからE.D.I.T.H.（イーディス。トニーが作った防衛システム）を受け取り、ドローンで幻影を本物の被害に見せて、トニーのあとのヒーローとして世に出ることです。

ラストは2つあります。ミッドクレジットでは、ベックの映像が出て、ピーターの正体が世間に知られます。ポストクレジットでは、本編に出ていたフューリーとヒルが、スクラル人だったと分かります。時期は『エンドゲーム』の8か月後です。冒頭の学校のニュースで、生徒が、消えた人たちが戻ったのは8か月前だと説明します。

## ミステリオの嘘と、本当のこと

ベックの語る話は、ヴェネツィアのあと、フューリーが紹介する場面で出ます。フューリーは、ベックは地球の人だが、ピーターの地球ではない、と言います。現実は複数ある、という説明に続けて、ベックは、ここは地球の次元616で、自分は地球833から来た、と話します。ピーターは、マルチバースがあるのか、と驚きます。

ベックは、元素から生まれたエレメンタルズが、自分の地球を滅ぼし、家族も殺されたと話します。自分は最後に残った部隊にいて、敵を遅らせただけで、いま同じ座標が攻撃されている、という説明です。

本当のことは、ピーターがE.D.I.T.H.を渡して去ったあとの、ベックと仲間の乾杯の場面で、観客に明かされます。

| ベックが語ったこと | 作中で分かること |
|---|---|
| 地球833から来た兵士で、故郷をエレメンタルズに滅ぼされた | この身の上話は、仲間のグーテス・グートマンが作った作り話。ベックは、まったく馬鹿げているが、今の人々が信じる話そのものだ、と乾杯で話す |
| エレメンタルズが、ヨーロッパの各地を襲っている | 幻影（ホログラム）とドローンで作ったもの。E.D.I.T.H.の軌道上の武装ドローンが、規模を大きくする。本物の被害は、ドローンの攻撃 |
| ピーターと組んで戦う味方 | 目的は、ピーターからE.D.I.T.H.を受け取ること |
| （自分の経歴は話さない） | 元スターク・インダストリーズの社員。仲間も元社員 |

本作は、マルチバースが存在しないとは言っていません。嘘だと分かるのは、別の地球から来た兵士、という身の上話のほうです。

## ミステリオの目的は、ベック本人の台詞で決まる

乾杯の場面で、ベックは動機を自分で話します。

ベックが設計したホログラムのシステムを、トニーは、セラピー用の機械に変えて、B.A.R.F.という名前を付けました。ベックは、人生の仕事にそんな名前を付けられた、と言います。間違いだと伝えたところ、不安定だと言われて解雇されました。B.A.R.F.は、『シビル・ウォー』でトニーが大学の講演で見せる装置で、トニーはその場で費用を6億1100万ドルと言います。ベックが乾杯で出す数字と同じです。

そのうえでベックは、トニーがいなくなった今がチャンスで、誰かがその穴を埋めることになる、と言います。今は、一番頭がよくても、一番ふさわしくても、誰も話を聞いてくれない。マントで飛ぶか、手からレーザーを出さないと聞いてもらえない。自分にはマントとレーザーがある。自分たちの技術とE.D.I.T.H.があれば、ミステリオは地球で一番のヒーローになり、誰もが耳を傾ける、という話です。

E.D.I.T.H.を手に入れた経緯も、乾杯で語られます。トニーの死後、E.D.I.T.H.が自分たちにも国防総省にも渡されず、子どもに渡されたと分かった、という話です。ピーターは、トニーが次のトニー・スタークに託したものだが、自分は準備ができていないと考えて、E.D.I.T.H.の管理をベックに移していました。

## 幻影のしくみと、仲間4人の担当

ベックは、乾杯の順に、仲間の担当を挙げます。

| 仲間 | 担当 |
|---|---|
| ウィリアム・ギンター・リヴァ | ベックの幻影の技術と、武装ドローンを組み合わせる。ベックの言い方では、強力な幻影と、本物の被害 |
| グーテス・グートマン | 作り話（設定）を作る |
| ヴィクトリア・スノー | 各地で、フューリーの衛星を使って電磁パルスを起こし、嘘を裏づける |
| ジャニス・リンカーン | トニーの死後、E.D.I.T.H.が自分たちでも国防総省でもなく、子ども（ピーター）に渡されると突き止めた |

リヴァは、『アイアンマン』（2008）でオバディア・ステインの部下として出ていた人物で、演じるのも同じピーター・ビリングスリーです。

## ピーターが気づくまで

プラハのあと、火のエレメンタルズから取れた装置が起動して、幻影を映します。ピーターは、これは投影機だ、と気づきます。

ベルリンでピーターを迎えたフューリーとヒルは、ベックが幻影で化けたものでした。ピーターは、ミステリオもエレメンタルズも全部偽物だと話します。ほかに誰に話したかと聞かれたところで、ベックが現れます。フューリーは死ぬ必要があったが君は違う、と言って、幻影でピーターを追い詰めます。そのあと、再び現れたフューリーに、誰に話したのかと問い詰められて、ピーターはネッドとMJ、ネッドが話したかもしれないベティの名前を言ってしまいます。これもベックの幻影で、ベックは、これで友達はみんな死ななければならない、と言います。ピーターは列車にひかれます。

ピーターが目を覚ましたのはオランダの留置場で、ハッピーに連絡して、プライベート・ジェットでロンドンに向かいます。ベックがロンドンで友達を狙うのは、ピーターから名前を聞いて、ばれるのを恐れたためです。

ロンドンのタワー・ブリッジで、ピーターは新しいスーツを着て、ホログラムの中のドローンを壊します。ベックは、ドローンを全部撃て、と命じます。攻撃範囲の中にいる、と警告されても聞かず、ベック自身がドローンの弾に当たります。

ピーターは、もうだまされない、と言って、E.D.I.T.H.にドローンを止めるよう頼みます。E.D.I.T.H.が、取り消しの手順を全部実行しますか、と聞き、ピーターは、やれ、全部実行して、と答えます。

ベックは死ぬ前に、人は信じたがる、今は何でも信じる、という趣旨のことを言います。

## ラスト（1）ミッドクレジットで、ピーターの正体がばれる

ニューヨークのニュース番組が、ロンドンの攻撃に関する新事実として、匿名の提供者の映像を流します。ベックの死の直前とされる映像です。

映像の中のベックは、エレメンタルを次元の裂け目に戻したが、この橋から生きて出られない、と話します。スパイダーマンが理由もなく攻撃してきて、スタークの技術の武装ドローンの軍団を持っている、次のアイアンマンになるのは自分だと言っている、とも言います。そこでE.D.I.T.H.が、ドローン攻撃を実行しますか、大きな被害が出ます、と聞き、スパイダーマンが、やれ、全部実行して、と答えます。

映像のスパイダーマンの返事は、ロンドンの戦いでピーターがE.D.I.T.H.に返した言葉と同じです。ロンドンでは取り消しの手順への返事でしたが、映像ではドローン攻撃への返事に聞こえます。映像を切り貼りしたという説明は、作中にはありません。

映像は、TheDailyBugle.netというサイトに載ります。J・ジョナ・ジェイムソンが、スパイダーマンがミステリオを殺した証拠だと言い、ミステリオを、地球を守って命を落とした、次元を超えた戦士と呼びます。続けて、映像の中のベックが、スパイダーマンの本名は、と言いかけ、映像が一瞬途切れたあと、ピーター・パーカーだ、と言います。ピーターの写真が画面に出て、ピーターが驚きます。

映像は、ベックが被害者で、スパイダーマンがドローンで攻撃した犯人に見える形で流れます。誰が提供したのかは、作中では匿名のままです。ベックはベルリンの場面で、ピーターが自分に話した内容を引いているので、ピーターから聞いていたことは分かります。

## ラスト（2）ポストクレジットで、フューリーが偽物だったと分かる

本編に出ていたフューリーとヒルは、スクラル人のタロスとソレンが化けた姿です（ベルリンで出てくる2人は、ベックの幻影）。ポストクレジットで、車に乗ったフューリーとヒルが笑い合い、2人の姿がタロスとソレンに変わります。

ソレンが、本人に言わないと、と言うと、タロスは、うまくいった、あの子は乗り切った、と言い訳します。全部が偽物だなんて分かるわけがない、演技も幻影も衣装も、とてもよくできていた、姿を変えられる者として恥ずかしい、という言い方です。ミステリオの幻影を見抜けなかったことが、タロスにとって恥ずかしいことだと、この台詞で分かります。

タロスは携帯電話で、フューリーに電話をかけます。約1週間前に、言われたとおりピーターにメガネを渡したが、そのあと全部が狂った、みんながアベンジャーズはどこだと聞くので、戻ってきてほしい、という内容です。宇宙船の中にいる本物のフューリーが電話を切ります。部屋にはビーチのホログラムが映っています。フューリーは立ち上がり、みんな仕事に戻れ、誰か私の靴を知らないか、と言います。

本編のどの場面までがタロスなのかは、作中ではっきり言われません。ポストクレジットでは、本物のフューリーが宇宙船にいる姿が映ります。

タロスは、『キャプテン・マーベル』（1995年の話）で初めて出たスクラル人です。妻のソレンも、同じ『キャプテン・マーベル』に出ています。

## 『ノー・ウェイ・ホーム』とのつながり

『ノー・ウェイ・ホーム』は、本作の直後から始まります。ミッドクレジットの映像でピーターの正体が知られたことが、話の出発点です。日本公開は2022年1月7日です。
