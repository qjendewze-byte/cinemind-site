# 現実逃避したい夜に観る映画14本【気分別】

何も手につかない夜ってありますよね。

仕事のことを考えたくないのにスマホを開いて、結局また仕事のことを考えている。そういう夜です。

こういうときに映画を探すと「感動の名作」みたいなのが出てきますが、たぶん今はそういう気分じゃないと思います。欲しいのは、観ている間だけ全部忘れられるやつです。

同じ「現実逃避したい」でも、そのときの気分でハマる映画は変わります。なので気分ごとに分けました。

- とにかく違う世界に行きたいとき
- 何も考えたくないとき
- 考えすぎて止まらないとき
- 誰とも関わりたくないとき

上映時間も入れてあります。寝る前だと、そこが一番大事だったりするので。

## とにかく違う世界に行きたいとき

今いる場所から離れたいだけ、というときです。話の筋より、景色を見ていたい。

### アバター（162分）

パンドラの夜の森。地面も植物も生き物も光ります。

ストーリーを追うのをやめて、ただ景色を眺めているだけで時間が過ぎていきます。長い映画ですが、そのわりに疲れません。行き先としては、この14本で一番遠いところです。

### レディ・プレイヤー1（140分）

舞台はゲームの中。知っているキャラクターが次から次に出てきます。

「あ、あれだ」と言っているうちに終わります。考える暇がありません。

### 第9地区（111分）

南アフリカのスラムに宇宙人が住みついている、という話です。

ドキュメンタリーみたいな撮り方で、画面はずっと汚いです。きれいな世界に行きたい人には向きません。ただ「今いるところと全然違う」という意味では、これが一番強いです。

### オブリビオン（124分）

人がいなくなった地球で、ひとり設備の点検を続ける男の話。

静かで、音が良くて、画面がきれいです。誰とも喋りたくない日にどうぞ。

[[CARD:131]]

## 何も考えたくないとき

考えるのに疲れている日です。話は単純でいいし、単純なほうがいいです。

### キングスマン（129分）

スパイ映画の顔をした悪ふざけです。

教会のシーンは、音楽と暴力の組み合わせが完全にやりすぎています。品はありません。そこがいいんです。

### トップガン マーヴェリック（131分）

実際の戦闘機で撮っています。

CGを見慣れた目に、本物のGがかかった映像はかなり刺さります。話は単純です。単純でいい日があります。

### オール・ユー・ニード・イズ・キル（113分）

死ぬたびに同じ朝に戻って、少しずつ強くなっていく話。

ゲームのリトライに近い構造で、うまくなっていく過程そのものが気持ちいいです。

[[CARD:144]]

## 考えすぎて止まらないとき

頭が勝手に動いてしまう夜は、「何も考えない」のは無理です。むしろ難しい映画のほうが向いています。他のことを考えている余裕がなくなるので。

### インセプション（148分）

他人の夢に潜って情報を盗む話。深く潜るほど時間の流れが変わります。

設定を理解するのに頭を使い切るので、自分の悩みを考えている場合ではなくなります。

### テネット（151分）

時間が逆に進みます。

正直、1回で全部わかる人は少ないと思います。ただ、わかるのを諦めた瞬間から、ただ映像を浴びる時間になります。わからないまま気持ちよくなれる、けっこう珍しい映画です。

### メッセージ（116分）

巨大な宇宙船が12機、地球に降りてきます。でも戦いません。

言語学者が、宇宙人の文字を解読しようとする話です。派手な場面はないですが、静かな緊張がずっと続きます。音を絞って観るのに合っています。

### インターステラー（169分）

宇宙と地球で時間の進み方が変わる話。

難しいです。ただ、わからないところがあっても映像と音で持っていかれます。

[[CARD:100]]

## 誰とも関わりたくないとき

人がほとんど出てこない3本です。

### アイ・アム・レジェンド（100分）

人類が消えたニューヨークで、ひとり暮らしを続ける男の話。

誰もいない街を犬と歩く場面が長く続きます。

[[CARD:151]]

### パッセンジャー（116分）

宇宙船の中で、たったひとりだけ90年早く目覚めてしまいます。

誰もいない豪華な船を全部自分で使える序盤は、正直うらやましいです。

[[CARD:94]]

### LIFE／ライフ（104分）

宇宙ステーションで地球外生命体が目を覚まします。

逃げ場のない狭い空間の話なので、現実を思い出す隙がありません。怖いのが平気な人限定です。

[[CARD:141]]

## 時間がないときは

明日も仕事、という夜もあると思います。2時間を切るのはこの6本です。

| 作品 | 上映時間 |
|---|---|
| アイ・アム・レジェンド | 100分 |
| LIFE／ライフ | 104分 |
| 第9地区 | 111分 |
| オール・ユー・ニード・イズ・キル | 113分 |
| メッセージ | 116分 |
| パッセンジャー | 116分 |

逆に、明日が休みなら『アバター』（162分）か『インターステラー』（169分）です。長さを気にしなくていい日のほうが向いています。

## おわりに

現実逃避に向いている映画と、面白い映画は、けっこう別物です。

あと、途中で寝ても大丈夫です。最後まで観るのが目的じゃないので。
