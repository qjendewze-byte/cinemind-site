# スパイダーマン映画の見る順番は？実写9作を公開順に、新作の前は3本

※作品名と、『ノー・ウェイ・ホーム』に他のシリーズのピーターと敵が出ることには触れますが、結末は書いていません。映画だけを扱い、ドラマは入れていません。

スパイダーマンの実写映画は9作で、サム・ライミ版（3作）、アメイジング版（マーク・ウェブ監督、2作）、トム・ホランド版（4作）の3つのシリーズに分かれます。3つは別々の世界の話なので、公開順（ライミ版、アメイジング版、ホランド版）に見れば迷いません。全部で1,219分（20時間19分）です。

2026年7月31日公開の『ブランド・ニュー・デイ』の公式あらすじは、前作『ノー・ウェイ・ホーム』の出来事から4年後の話だと書いています。新作の前に見るなら、ホランド版の『ホームカミング』『ファー・フロム・ホーム』『ノー・ウェイ・ホーム』の3本、410分（6時間50分）です。

## どのルートで見るか

| ルート | 内容 | 時間 |
|---|---|---|
| 新作の前の3本 | ホームカミング → ファー・フロム・ホーム → ノー・ウェイ・ホーム | 410分（6時間50分） |
| ホランド版だけ | 新作の前の3本に『ブランド・ニュー・デイ』を足す | 555分（9時間15分） |
| アベンジャーズの作品も入れる | シビル・ウォー → ホームカミング → インフィニティ・ウォー → エンドゲーム → ファー・フロム・ホーム → ノー・ウェイ・ホーム | 888分（14時間48分） |
| ライミ版だけ | スパイダーマン → 2 → 3 | 387分（6時間27分） |
| アメイジング版だけ | アメイジング・スパイダーマン → 2 | 277分（4時間37分） |
| 全部 | 実写9作を公開順に | 1,219分（20時間19分） |

「新作の前の3本」は、cinemindでの整理です。

## アベンジャーズとの間の順番

ホランド版のピーターが最初に出るのは『シビル・ウォー』で、『インフィニティ・ウォー』『エンドゲーム』にも出ています。『ファー・フロム・ホーム』は『エンドゲーム』の8か月後の話で、『エンドゲーム』の出来事を前提に始まります。

アベンジャーズの作品も入れるなら、『シビル・ウォー』→『ホームカミング』→『インフィニティ・ウォー』→『エンドゲーム』→『ファー・フロム・ホーム』→『ノー・ウェイ・ホーム』の順です。マーベル全体の順番は、次の記事にまとめています。

## 3つのシリーズの関係

ライミ版からアメイジング版への切り替えは、作り直し（リブート）です。アメイジング版は、ライミ版の三部作のリブートとして作られました。

その後、2015年にソニーとマーベル・スタジオが提携を発表します。アメイジング版は2作で終わり、トム・ホランドのスパイダーマンがMCU（マーベル・シネマティック・ユニバース）に入りました。

3つは別の世界の話で、つながるのは『ノー・ウェイ・ホーム』の1本だけです。この作品に、ライミ版とアメイジング版の人物が登場します。

## ライミ版・アメイジング版は、いつ見ればいい？

見るなら『ノー・ウェイ・ホーム』の前です。『ノー・ウェイ・ホーム』には、この2つのシリーズのピーターと敵が出てきます。主な敵は次の3人です。

| 『ノー・ウェイ・ホーム』の主な敵 | 元の作品 |
|---|---|
| グリーン・ゴブリン | ライミ版『スパイダーマン』（2002年） |
| ドック・オク | ライミ版『スパイダーマン2』（2004年） |
| エレクトロ | アメイジング版『アメイジング・スパイダーマン2』（2014年） |

ほかに、サンドマン（『スパイダーマン3』）とリザード（『アメイジング・スパイダーマン』）、ライミ版とアメイジング版のピーターも出ます。時間がなければ、表の3人の元の3本に絞る手もあります（121分、127分、141分で、合計389分）。これはcinemindでの整理で、見ないと話が分からないという意味ではありません。

## スパイダーバースとヴェノムは、表に入れていない

次の作品は、ピーター・パーカーが主人公の実写ではないので、9作の表には入れていません。

- **スパイダーバース（アニメ）**: 主人公はマイルス・モラレスです。『スパイダーマン：スパイダーバース』（日本公開 2019年3月8日、117分）と『スパイダーマン：アクロス・ザ・スパイダーバース』（2023年6月16日、140分）があります。
- **ヴェノム系の作品**: 『ヴェノム』3作、『モービウス』『マダム・ウェブ』『クレイヴン・ザ・ハンター』です。スパイダーマン本人が主役の作品ではありません。ホランド版とつながるのは、エンドクレジットの短い場面だけです（『レット・ゼア・ビー・カーネイジ』と『ノー・ウェイ・ホーム』のヴェノム、『モービウス』のトゥームス）。
