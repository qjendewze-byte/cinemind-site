# クアントマニアの征服者カーンとは誰？目的とロキとの関係（ネタバレあり）

※『アントマン＆ワスプ：クアントマニア』の結末と、ミッドクレジット、ポストクレジットの内容まで書いています。ドラマ『ロキ』シーズン1の設定にも触れます。

征服者カーンは、自分の変異体たちに恐れられて量子世界に追放されていた人物です。時間とマルチバースを移動できる自分の船のエンジンのコアを取り戻して脱出しようとし、スコットにそれを盗ませるため、娘のキャシーを人質に取ります。『ロキ』の在り続ける者との関係は、作中では説明されません。映画の台詞に「在り続ける者」という言葉は出てこないので、『ロキ』を見ていないと、つながりは分かりません。

[[IMG:antman3-kang.png|カーンと『ロキ』の在り続ける者、エンドクレジットの人物のつながり]]

## 映画の台詞で分かるカーンの話

| 場面 | 分かること |
|---|---|
| 量子世界の住人の話 | 上から来た者は、カーンに狙われる。カーンは「征服者」と呼ばれ、人々から恐れられている |
| 来歴の説明 | カーンは、量子世界に墜落したのではなく、追放された。そこは、時間と空間の外にある、カーンを閉じ込められる唯一の場所だった。誰が追放したかは、説明するジャネットも知らない。カーンの船は壊された |
| カーン自身の話 | 自分は直線の時間に生きていなくて、終わりを知っている。いくつもの反乱を鎮め、いくつの世界を征服し、何人のアベンジャーズを殺したと思うか、と問いかける形で言って、カーンだと名乗る |
| 追放した相手 | 自分の変異体たちに恐れられて、追放された。来るのは自分で、たくさんの自分だと話す |
| ジャネットとのやりとり | 時間を壊したのは自分の変異体たちだと、カーンが話す |
| 目的 | 船のエンジンのコアを取り戻して、脱出する。コアは、ジャネットが爆破して、使えない大きさにしてしまった。コアにたどり着くにはピム粒子が要る。カーンはスコットに、縮んでコアの中心に入り、元の大きさに戻して持ってくるよう命じる |
| スコットとキャシー | カーンはキャシーを人質に取って、スコットにコアを盗ませようとする |

## 『ロキ』を見ていないと分からない？

カーンの目的は、映画の台詞だけで分かります。『ロキ』を見ると分かるのは、変異体がたくさんいる、という話の背景のほうです。

| 映画の中で分かること | 映画では説明されないこと |
|---|---|
| カーンは量子世界に追放された征服者（台詞） | 在り続ける者が誰か、TVAが何か |
| 自分には変異体がたくさんいて、その変異体たちに追放された（台詞） | 変異体とは何か |
| 時間とマルチバースを移動できる船を持つ（台詞） | 在り続ける者とカーンのつながり |
| ミッドクレジットで、多数のカーンが集まる（場面） | 集まったカーンたちが、それぞれ誰か |
| ポストクレジットで、ロキとメビウスが調べている（場面） | ロキとメビウスが、なぜ調べているのか |

## カーンと「在り続ける者」はどういう関係？

映画の中では、カーンと在り続ける者の関係は説明されません。共通しているのは、どちらもジョナサン・メジャースが演じていることです。

『ロキ』（シーズン1は2021年）の在り続ける者は、TVA（時間変異取締局）を作った31世紀の科学者で、自分の変異体たちが時間の流れを壊すのを防ぐためにTVAを作った、という人物です。

映画のカーンが、自分の変異体がたくさんいて、その変異体たちに追放されたと話すのは、この『ロキ』の話と重なります。ただ、映画の中には在り続ける者の名前もTVAも出てこないので、映画だけ観た人にはこの重なりは分かりません。

## カーンは最後どうなった？

最後は、スコットとホープが、カーンをコアの中に投げ込みます。地上に戻ったスコットは、本当に倒したのかと迷い、カーンが言っていた、これから来るもののことを思い出しますが、考えすぎないことにします。

## 最後に出てくるロキは何をしている？エンドクレジットの2つの場面

ポストクレジットでは、ロキとメビウスが、もう1人のカーンを見て調べています。

| 場面 | 起きること |
|---|---|
| ミッドクレジット | 複数のカーンが集まる場面。ファラオのような姿や、鋼のスーツ姿のカーンもいて、作中の台詞では名前は出ない。追放されたカーンが死んだことが話題になり、殺したのは自分たちではなく彼らで、彼らはマルチバースに触れ始めている、という話が出る。その彼らが誰かは、台詞では言わない。全員を集める、という話もある |
| ポストクレジット | もう1人のカーン（ジョナサン・メジャース）が、未来の技術を人々に紹介している。ロキ（トム・ヒドルストン）とメビウス（オーウェン・ウィルソン）が、それを見て調べている。この2人はクレジットなしの出演で、台詞に名前は出ない |
