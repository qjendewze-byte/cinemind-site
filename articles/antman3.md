# クアントマニアの征服者カーンとは誰？在り続ける者との関係（ネタバレあり）

※『アントマン＆ワスプ：クアントマニア』の結末と、ミッドクレジット、ポストクレジットの内容まで書いています。ドラマ『ロキ』の登場人物にも触れます。

征服者カーンは、量子世界に追放されていた人物で、時間とマルチバースを移動できる自分の船のエンジンのコアを取り戻して、そこから脱出しようとします。そのコアを取り戻すために、スコットに盗ませようとして、娘のキャシーを人質に取ります。ドラマ『ロキ』に出てくる「在り続ける者」とは、別のタイムラインの変異体、つまり同じ人物の別の時間軸の姿だとされています。ただし映画の台詞に、「在り続ける者」という言葉は出てきません。映画の中でカーンの目的は完結していて、「在り続ける者」との関係は説明されません。

[[IMG:antman3-kang.png|カーンと『ロキ』の在り続ける者、エンドクレジットの人物のつながり]]

## 映画の台詞で分かるカーンの話

| 場面 | 分かること |
|---|---|
| 量子世界の住人の話 | 上から来た者は、カーンに狙われる。カーンは「征服者」と呼ばれ、人々から恐れられている |
| 来歴の説明 | カーンは、量子世界に墜落したのではなく、追放された。そこは、時間と空間の外にある、カーンを閉じ込められる唯一の場所だった。誰が追放したかは、説明する側は知らない。カーンの船は壊された |
| カーン自身の話 | 自分は直線の時間に生きていなくて、終わりを知っている。何度も反乱を鎮め、世界を征服し、アベンジャーズを殺してきたと言って、カーンだと名乗る |
| 追放した相手 | 自分の変異体たちに恐れられて、追放された。来るのは自分で、たくさんの自分だと話す |
| 目的 | 船のエンジンのコアを取り戻して、脱出する。コアは、ジャネットが爆破して小さくし、量子世界のどこかにある。取り戻すにはピム粒子が要る |
| スコットとキャシー | カーンはスコットに、コアを盗んでくるよう強要する。キャシーを人質に取る |

時間をもてあそんだのは、自分と変異体たちだ、という話も、カーンとジャネットのやりとりの中で出ます。

## カーンと「在り続ける者」はどういう関係？

カーンは、ドラマ『ロキ』（シーズン1は2021年）の「在り続ける者」とは別のタイムラインの変異体だとされています。どちらも、ジョナサン・メジャースが演じています。

『ロキ』の在り続ける者は、TVA（時間変異取締局）を創設した、31世紀の科学者です。神聖時間軸が、自分の邪悪な変異体によって壊されるのを防ぐために、TVAを作りました。

映画の中でカーンが「変異体がたくさんいる」と話すところは、ここにつながります。ただ、映画の中では、在り続ける者の名前もTVAも出てこないので、つながりは説明されません。

## 『ロキ』を見ていないと分からない？

| 映画の中で分かること | 映画では説明されないこと |
|---|---|
| カーンは量子世界に追放された征服者（台詞） | 在り続ける者が誰か、TVAが何か |
| 自分には変異体がたくさんいて、その変異体たちに追放された（台詞） | 変異体とは何か |
| 時間とマルチバースを移動できる船を持つ（台詞） | 在り続ける者とカーンのつながり |
| ミッドクレジットで、多数のカーンが集まる（場面） | 各カーンの名前の由来 |
| ポストクレジットで、ロキとメビウスが調べている（場面） | ロキとメビウスが、なぜ調べているのか |

カーンの目的は、映画の台詞だけで分かります。『ロキ』を見ると分かるのは、変異体がたくさんいる、という話の背景のほうです。

## カーンは最後どうなった？

カーンは、コアに巻き込まれて倒されます。スコットが、カーンは消えたと口にします。

## エンドクレジットの2つの場面

| 場面 | 起きること |
|---|---|
| ミッドクレジット | 複数のカーンが集まる場面。イモータス、ラマ・タト（ファラオのような姿）、センチュリオン（鋼のスーツ）と呼ばれるカーンがいる。追放されたカーンが死んだことが話題になり、殺したのは自分たちではなく、アベンジャーズのほうだという話が出る。全員を集める、という話もある |
| ポストクレジット | ヴィクター・タイムリー（カーンの変異体）が、未来の技術を人々に紹介している。ロキ（トム・ヒドルストン）とメビウス（オーウェン・ウィルソン）が、それを見て調べている。この2人はクレジットなしの出演で、台詞に名前は出ない |

ヴィクター・タイムリーは、ドラマ『ロキ』のシーズン2にも出てきます。
