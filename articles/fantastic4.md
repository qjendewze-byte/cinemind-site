# ファンタスティック4 ファースト・ステップはMCUとつながってる？

※ミッドクレジットに出てくる人物と、過去作の俳優のカメオに触れています。『デッドプール＆ウルヴァリン』のカメオにも触れます。ギャラクタスとの戦いの結末は書いていません。

『ファンタスティック４：ファースト・ステップ』は、MCUの本筋（アース616）とは別の世界、アース828の話として作られています。1960年代風の世界を舞台にした、MCUの第37作目です。過去のファンタスティック・フォー映画（2005年版、2015年版）とは、製作会社もキャストも監督も別で、本作の中で過去の映画とつながるのは、1994年版（劇場未公開）の4人を演じた俳優のカメオです。2005年版のジョニーを演じたクリス・エヴァンスは、本作ではなく『デッドプール＆ウルヴァリン』に、その世界の人物として出ています。

見ておくと意味が分かる作品は、次の節にまとめました。

## 前に見ておく作品はある？

作中の接点がはっきりしているのは、次の3本です。

| 作品 | 本作との接点 |
|---|---|
| 『サンダーボルツ*』（2025年5月2日・126分） | ポストクレジット（本作の14か月後）に、別の次元から来た「4」のマークの宇宙船が現れる。本作とMCUの本筋をつなぐ、作中の場面 |
| 『ドクター・ストレンジ／マルチバース・オブ・マッドネス』（2022年） | リード・リチャーズが、ジョン・クラシンスキー演じる別の世界（アース838）の人物として先に出ている。本作のリード（ペドロ・パスカル）とは別の人物 |
| 『アベンジャーズ／エンドゲーム』（2019年） | ミッドクレジットのドクター・ドゥームを演じるロバート・ダウニー・Jr.が、エンドゲームまでトニー・スターク（アイアンマン）を演じていた |

公式のあらすじは、宇宙ミッションの事故で能力を得た4人が人々を守ってきたが、リードのある行動をきっかけに、惑星を食べる宇宙神ギャラクタスが地球に迫る、という4人とギャラクタスの話で、ほかのMCU作品には触れていません。

## MCUの本筋とはつながってる？

| どこで | 内容 |
|---|---|
| 本作の舞台 | MCUの本筋（アース616）とは別の世界のアース828。時代設定は1960年代風で、チームが活動を始めて4年目の世界 |
| ミッドクレジット | 本作の4年後。4歳になったフランクリン（スーの息子）の前に、スーが目を離した隙に、銀の仮面を持った人物が現れる。顔は映らないが、フードの色と手に持つマスクの形から、ドクター・ドゥーム（ロバート・ダウニー・Jr.）と分かる |
| 他の作品のおまけ映像 | 『サンダーボルツ*』のポストクレジットに、「4」のマークの宇宙船が現れる（上の表） |
| 首脳会談の場面 | スーが各国代表の前で演説する場面で、「ラトヴェリア」と書かれた席が空いている。ラトヴェリアは、原作コミックでドゥームが治める国 |

## 過去のファンタスティック・フォー映画との関係

| 作品 | 日本公開・上映時間 | 本作との接点 |
|---|---|---|
| ファンタスティック・フォー（1994年、ロジャー・コーマン製作） | 劇場公開されていない | 4人を演じた俳優4人が、本作にカメオで出る。2人はテレビ番組のナレーション、2人はジョニーに助けられる作業員。4人そろって、チームに感謝する市民としても出る |
| ファンタスティック・フォー 超能力ユニット（2005年） | 2005年9月17日・110分 | ジョニーはクリス・エヴァンス。本作の中の接点はない |
| ファンタスティック・フォー：銀河の危機（2007年） | 2007年9月21日・92分 | 2005年作の続編。シルバーサーファーが出る |
| ファンタスティック・フォー（2015年） | 2015年10月9日・100分 | リブート版。マイルズ・テラー、ケイト・マーラ、マイケル・B・ジョーダン、ジェイミー・ベル主演 |
| デッドプール＆ウルヴァリン（2024年） | 2024年7月24日・127分 | 旧作のジョニー（クリス・エヴァンス）が、虚無の人物として出る。本作のジョニーはジョセフ・クイン |

旧作のうち1994年版を除く作品は、20世紀フォックスの製作です。2019年にディズニーが21世紀フォックスの買収を完了し、マーベルの映画化権がディズニーに移ったので、MCUで扱えるようになりました。本作はマーベル・スタジオの製作です。

## ドゥームズデイとの関係

2026年11月17日時点で、『アベンジャーズ／ドゥームズデイ』の日本公式サイトのキャスト欄に、次の人物が載っています。

| 本作の人物 | ドゥームズデイ公式キャスト欄 |
|---|---|
| リード・リチャーズ／ミスター・ファンタスティック | 載っている（ペドロ・パスカル） |
| スー・ストーム／インビジブル・ウーマン | 載っている（ヴァネッサ・カービー） |
| ジョニー・ストーム／ヒューマン・トーチ | 載っている（ジョセフ・クイン） |
| ベン・グリム／ザ・シング | 載っている（エボン・モス＝バクラック） |
| ドクター・ドゥーム | 載っている（ロバート・ダウニー・Jr.） |
| ハービー、ギャラクタス、シルバーサーファー | 載っていない |

載っていない人物が出ないという意味ではありません。公式のあらすじでは、ストーリーも出演キャラクターも公開まで明かされない、とされています。ドゥームズデイは2026年12月18日公開で、日米同時、監督はルッソ兄弟です。キャスト欄は更新されることがあります。ドゥームズデイの前に見る作品の全体は、こちらにまとめています。
