# ストレンジ2のワンダはなぜ敵に？ワンダヴィジョンは要る？（ネタバレあり）

※『ドクター・ストレンジ／マルチバース・オブ・マッドネス』の結末と、エンドクレジットの2つの場面まで書いています。ドラマ『ワンダヴィジョン』の結末にも触れます。

ワンダが敵になったのは、別の宇宙にいる自分の子どもたちのところへ行きたいからです。そのために、別の宇宙へ渡る力を持つ少女アメリカ・チャベスを狙います。この目的は、映画の中のワンダの台詞で完結していて、『ワンダヴィジョン』を見ていなくても分かります。映画では説明されないのは、子どもたちと別れた経緯と、ワンダがダークホールドをどこで手に入れたかです。

ミッドクレジットでストレンジに声をかける女性は、シャーリーズ・セロンが演じるクレアです（下の「ミッドクレジットの女性は誰？」に書いています）。

[[IMG:doctorstrange2-wanda.png|ワンダが敵になるまでの、ドラマ『ワンダヴィジョン』と映画『マッドネス』の流れ]]

## 『ワンダヴィジョン』で起きたこと

ワンダは、ウエストビューの町を力場のヘックスで包み、その中で夫のヴィジョンと、双子の息子ビリー、トミーと暮らしていました。ヘックスの中のヴィジョンも、ビリーとトミーも、ワンダが無から創造したものです。ワンダは、自分の力が町の住民を苦しめていたと知り、ヘックスを消します。子どもたちとは、ここで別れます。

最終話のエンドクレジット後の場面では、ワンダが山の中でダークホールドを読み、子どもたちの助けを呼ぶ声を聞きます。ドラマでは、ダークホールドは魔女アガサ（アグネスとして登場）が持っていた書です。映画にアガサは出てこず、名前も出ません。

## ワンダの目的は？映画の台詞を順に

| 場面 | ワンダとストレンジの話 |
|---|---|
| ストレンジがワンダを訪ねる | ストレンジは、ウエストビューの件で来たのではないと言い、マルチバースで狙われている少女アメリカの話をする。ワンダは、ヴィジョンがマルチバースはあると言っていた、と答える |
| ストレンジが気づく | ワンダは、アメリカの名前を、ストレンジから聞いていないのに口にする。ストレンジは、黒幕がワンダだと気づく |
| ダークホールド | ストレンジは、触れた者を堕落させる呪われた書だと言う。ワンダは、ダークホールドは真実を見せてくれただけで、失ったものはすべて取り戻せると答える |
| 目的 | ワンダは、この現実を出て、子どもたちと一緒にいられる宇宙へ行くと言う。ストレンジが、子どもたちは魔法で作ったもので実在しないと言うと、ワンダは、母親はみんなそうする、と返す |
| アメリカを狙う理由 | アメリカの力を取り込めば、別の宇宙の自分のところへ行ける。ストレンジは、力を奪えばアメリカは死ぬと言って止める |
| カマー・タージが落ちた直後 | ワンダは、反射を通してストレンジに話しかけ、自分は怪物ではなく母親だと言う。子どもたちは別の宇宙にいて、毎晩同じ夢を見る、と話す |
| 手段 | ダークホールドに書かれた魔術で、別の宇宙の自分に意識を乗り移らせる。カマー・タージの魔術師たちや、別の宇宙のイルミナティを襲う |

ワンダは、「スカーレット・ウィッチ」とも呼ばれます。ストレンジとウォンの会話では、現実を思いのままに書き換えられる存在で、ダークホールドに取りつかれた人物として話されます。

## ワンダはなぜ止まった？

アメリカが開いた扉の先で、別の宇宙のワンダの家に、この宇宙のワンダが現れます。その宇宙のビリーとトミーは、ワンダを見て怯え、自分たちの本当のお母さんではないと言います。ワンダは傷つけないと言いかけて言葉に詰まり、謝ります。

## ワンダは最後どうなった？死んだの？

ワンダは、ダークホールドを開いたのは自分だから閉じなければならない、と言い、あらゆる宇宙のダークホールドを燃やします。ワンダは自分の力でワンダゴア山の神殿を崩します。ワンダは崩れる神殿の中にいて、死んだとは台詞でも画面でも示されません。

## ワンダヴィジョンを見ていないと分かる？

ワンダが何をしたいのかは、映画の台詞だけで分かります。ドラマを見ると分かるのは、そう思うようになったきっかけ、つまり子どもたちとどう別れたかのほうです。

| 映画の中で分かること | 映画では説明されないこと |
|---|---|
| ワンダ自身が、ウエストビューで過ちを犯し、人を傷つけたと話す | ウエストビューで何が起きたか、誰が巻き込まれたか |
| 子どもたちは、ワンダが魔法で作ったものだと、ストレンジが言う | ビリーとトミーの様子、ヴィジョンの再現、ヘックスの中の暮らし |
| ダークホールドは持つ者を堕落させる。ワンダはそれを持っている | ワンダがダークホールドをどこで手に入れたか |
| スカーレット・ウィッチは、現実を書き換えられる存在（ウォンの説明） | ワンダがスカーレット・ウィッチと呼ばれるようになった経緯 |
| ワンダは子どもたちに会いたくて、アメリカを狙う | 子どもたちが消えた経緯 |

公式サイトのおすすめ作品欄にも、米Disney+が出した『アベンジャーズ／ドゥームズデイ』の予習15作品（報道による）にも、『ワンダヴィジョン』は入っていません。15作品のうちドラマは『ロキ』だけで、この映画は入っています。

## ミッドクレジットの女性は誰？

本編の最後に、ダークホールドを使った影響で、ストレンジの額に第三の目が開きます。ミッドクレジットでは、ストレンジに女性が声をかけ、あなたが起こしたインカージョンを一緒に直す、という話をします。女性は、武器で空間を切り裂き、暗黒次元への道を開きます。ストレンジは第三の目を開き、女性と一緒に飛び込みます。

この女性の役名がクレア（シャーリーズ・セロン）です。作中では名前は呼ばれず、クレアは日本語版Wikipediaの表記です。

暗黒次元は、1作目『ドクター・ストレンジ』で、ストレンジがドルマムゥと戦った世界です。

[[CARD:doctorstrange]]

エンドクレジットのあとには、別の宇宙のピザ屋台の男（ブルース・キャンベル）が、カメラに向かって話す場面があります。
