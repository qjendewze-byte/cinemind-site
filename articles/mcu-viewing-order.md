# マーベル見る順番ガイド｜公開順と時系列順、どちらで見るべきか

MCU（マーベル・シネマティック・ユニバース）は、2026年9月時点で劇場公開映画が38本あります。「どれから見ればいいか分からない」という悩みに対して、この記事は結論を先に出します。

**初見は公開順で見てください。** 理由は本文で説明します。

この記事には、以下の要素を用意しました。

- 全38作品の公開順一覧表（日本公開日基準）
- 全38作品の時系列順一覧表と、公開順とのズレの理由
- 初見に公開順を薦める理由
- 時間がない人向けの最短ルート（6作品）
- 全作品を見るのにかかる総時間

ストーリーの結末には触れていませんが、「どの作品がどの順番で起きる話か」という設定情報には触れています。作中の展開を一切知りたくない場合は、順番の表だけを参考にしてください。

## どちらの順番で見るべきか

**初見は公開順で見てください。** 時系列順は薦めません。理由は2つあります。

1本目は、MCUの伏線設計が公開順を前提にしているためです。「アベンジャーズ」でロキが登場して驚く、「シビル・ウォー」でチームが分裂して動揺する、といった感情の動きは、各作品が公開された順番で積み上がるように作られています。時系列順で見ると、後の作品で明かされる情報を先に知った状態で前の作品を見ることになり、驚きが減ります。

2本目は、時系列順には矛盾が残るためです。「ブラック・ウィドウ」や「ドクター・ストレンジ」のように、公開順と時系列順が入れ替わる作品を無理に並べ替えると、俳優の見た目や演出のトーンが前後の作品と合わなくなります。時系列順は「一度全部見たあとの復習」には向きますが、初見向けではありません。

時系列順が向いているのは、以下のような場合に限られます。

- 全作品を見終えたあと、設定を整理しながら見直したいとき
- 特定のキャラクター（例：キャプテン・アメリカ）の人生を追って見たいとき

## 最短ルート（時間がない人向け）

全38作品、総時間で見る余裕がない人向けに、最小限の6作品を選びました。

| 邦題 | 上映時間 | 選んだ理由 |
|---|---|---|
| アイアンマン | 126分 | MCU全体の起点。トニー・スタークの物語の出発点 |
| アベンジャーズ | 143分 | 初のチーム結成。以降の全作品の土台になる |
| ガーディアンズ・オブ・ギャラクシー | 122分 | 後の黒幕サノスと、インフィニティ・ストーンの概念を導入する |
| シビル・ウォー／キャプテン・アメリカ | 147分 | アベンジャーズが分裂する経緯。「インフィニティ・ウォー」冒頭の状況を理解するために必要 |
| アベンジャーズ／インフィニティ・ウォー | 149分 | サノスとの決着に向かう前編 |
| アベンジャーズ／エンドゲーム | 181分 | インフィニティ・サーガの完結編 |

**合計上映時間：868分（14時間28分）**

この6本で、MCUの主要な対立構造（チームの結成→分裂→サノスとの決着）を理解できます。個別のキャラクターの背景（ソー、ハルクなど）は省略しているため、6本を見終えたあとに興味を持った作品を追加で見ることを薦めます。

## 全部見るとどれくらいかかるか

38作品の上映時間を合計すると、**4,987分（83時間7分）**です。

1日2時間のペースで見た場合、4,987分 ÷ 120分 ＝ 約41.6日、**42日ほど**かかります。1日1本（平均2時間強）のペースなら、38日前後です。

## まとめ

- 初見は公開順で見てください。時系列順は復習向けです
- 日本では「インクレディブル・ハルク」が「アイアンマン」より先に公開されています
- 「ブラック・ウィドウ」は公開順と時系列順が大きくズレる代表例です
- 時間がない人は、まず6本（868分）から始めてください
- 全38作品を見るには、1日2時間のペースで約42日かかります

当サイトでは、フェーズ1と「ウィンター・ソルジャー」の個別レビューを公開しています。見終えた作品から、感想記事もあわせてご覧ください。
