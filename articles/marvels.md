# マーベルズの3人はなぜ入れ替わる？ラストの3人は誰？（ネタバレあり）

※『マーベルズ』の中盤から結末、ラスト、ミッドクレジットまで書いています。ドラマ『ミズ・マーベル』『ワンダヴィジョン』『ホークアイ』の内容にも軽く触れます。

作中の説明では、不安定なジャンプポイントに触れたモニカとキャロルの光の力がもつれ、3人が同時に力を使うと、場所が入れ替わるようになりました。カマラは3人目で、着けているバングルは、ジャンプポイントを乱しているダー・ベンのバンドと対になるもう1つです。2つのバンドが対で働くという伝説が語られたあと、それで入れ替わりの状況も説明がつく、という台詞が出ます。

[[IMG:marvels-swap.png|3人が入れ替わる仕組み。ダー・ベンのジャンプポイントでモニカとキャロルの力がもつれ、カマラのバングルとあわせて、同時に力を使うと場所が入れ替わる]]

## 3人は誰か

入れ替わるのは、キャロル、モニカ、カマラの3人です。3人の共通点は、光に関わる力です。キャロルは光のエネルギーを吸収でき、カマラは光を物質に変えられます。モニカも光に関わる力を持ちます。

| 人物 | 演じる人 | 力の出どころ |
|---|---|---|
| キャロル・ダンヴァース（キャプテン・マーベル） | ブリー・ラーソン | 『キャプテン・マーベル』 |
| モニカ・ランボー | テヨナ・パリス | ドラマ『ワンダヴィジョン』（2021年）。映画の中では、魔女のヘックスの障壁を通り抜けて、電磁波のあらゆる波長を見て操れるようになった、と自分で話す |
| カマラ・カーン（ミズ・マーベル） | イマン・ヴェラーニ | ドラマ『ミズ・マーベル』（2022年）。祖母から送られた魔法のバングルの光のエネルギーを使う |

## 入れ替わりの規則

| 場面 | 描かれること |
|---|---|
| 最初の入れ替わり | キャロルとモニカが、それぞれ別のジャンプポイントに触れる。直後に、3人の居場所が入れ替わる。モニカはキャロルのいた場所へ、カマラはモニカのいた宇宙ステーションへ、キャロルはカマラの家へ移る |
| 仮説 | カマラは、自分が光のエネルギーを使うたびに、別の場所に飛ばされると言う。ほかの2人も、その仮説に同意する台詞が続く |
| 理由の説明 | モニカとキャロルは、不安定なジャンプポイントに触れ、光に敏感な力を持つため、力が一時的にもつれた。光の力がもつれていて、3人が同時に力を使うと、場所が入れ替わる |
| ルール | 力は、入れ替わったあとも続く。3人が同時に力を使うと、位置が続けて入れ替わる |

## ジャンプポイントと2つのバンド

ジャンプポイントは、宇宙の移動の通り道です。敵のダー・ベンは、ハンマーとクリーのバンドを使って、ジャンプポイントを無理やり作ります。壊れたジャンプポイントは、不安定になります。

カマラのバングルは、ダー・ベンが使うバンドと対になるもう1つです。2つ1組で、宇宙のジャンプポイントのネットワークを作った、というクリーの伝説が語られます。カマラは、ダー・ベンが最初のジャンプポイントを開けたとき、祖母のバングルが変に光った、と話します。

ダー・ベンは、クリーの母星ハラを立て直すため、ほかの星から大気や資源を奪おうとしています。

## 入れ替わりはどう終わる？

ダー・ベンがカマラのバングルを奪い、2つのバンドを使おうとして消滅したあと、3人の力はもうもつれていない、という台詞が出ます。もつれが終わった理由は、台詞では説明されません。

時空には裂け目が残ります。モニカは、キャロルとカマラから力を受けて、裂け目を内側から閉じ、向こう側に取り残されます。

## ドラマを見ていないと分かる？

入れ替わりの理由は、映画の中の台詞だけで分かります。ドラマを見ると分かるのは、モニカが通ったヘックスが何だったのかと、カマラのバングルが祖母から届いた経緯のほうです。

| 映画の中で分かること | 映画では説明されないこと |
|---|---|
| 入れ替わりの理由（光の力のもつれ、ジャンプポイント）。モニカは、魔女のヘックスの障壁を通り抜けて力を得たと、自分で話す | ヘックスとは何か、ウエストビューで何が起きたか（『ワンダヴィジョン』） |
| カマラが、バングルの力で光を物質にする。バングルは祖母のもの | バングルが祖母から送られた経緯（『ミズ・マーベル』） |
| キャロルが、クリーの内戦のきっかけを作った | 『キャプテン・マーベル』でのスプリーム・インテリジェンスとの戦い |

ドラマ『ミズ・マーベル』の最終話でも、キャロルは、バングルが発した謎の光で、カマラと場所が入れ替わり、カマラの部屋に現れます。本作の入れ替わりの前触れにあたる場面です。

公式サイトのおすすめ作品欄に、ドラマ『ミズ・マーベル』『ワンダヴィジョン』は載っていません。先頭は『キャプテン・マーベル』です。

## ラストの3人は誰？（ケイト、ビースト、モニカが会う女性）

| 場面 | 描かれること |
|---|---|
| ラスト | カマラが、ピザの配達を装って、ケイト・ビショップ（ヘイリー・スタインフェルド）を訪ねる。カマラは、チームを作っていて、ケイトにも入ってほしいと話す。ケイトは、ドラマ『ホークアイ』（2021年）に出ている人物で、ニューヨークの戦いでクリント・バートンに救われて以来、彼に憧れている |
| ミッドクレジット | モニカが、見知らぬ場所で目覚め、母を泣いて呼ぶが、相手は戸惑う。母にそっくりの女性は、バイナリーという役名で、ラシャーナ・リンチが演じる |
| ミッドクレジット | 部屋に来た科学者のビースト（ケルシー・グラマー）は、モニカが時空の裂け目を通り、元の世界とは別の現実に来たのだろうと話す。チャールズ（プロフェッサーX）が様子を知りたがっている、とも言う。ビーストは、X-MENシリーズの人物 |

ビーストの出演は、予習の記事でも触れています。
