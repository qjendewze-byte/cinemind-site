# シャン・チーのテン・リングス（腕輪）の正体は？（ネタバレあり）

※『シャン・チー／テン・リングスの伝説』の結末と、エンドクレジットの2つの場面まで書いています。マンダリン（『アイアンマン3』）の詳しい話は、『アイアンマン3』の記事に書いています。

テン・リングスは、約1000年にわたって組織を率いてきたウェンウーが操る腕輪です。つけた者に、神のような力と永遠の命を与えます。組織の名前も、この腕輪から来ています。

決まっていないのは、腕輪の入手先です。冒頭の語りは、ウェンウーが腕輪をクレーターで見つけたとも、墓から盗んだとも言われている、と話し、どちらかは決めません。エンドクレジットの途中では、ウォンたちが腕輪を調べ、既知の素材や技術のどれとも違い、約1000年よりずっと古いと分かります。腕輪がメッセージを送っているらしいことも分かりますが、宛先は語られません。

[[IMG:shangchi-origin.png|テン・リングス（腕輪）の来歴の流れ。ウェンウーが手に入れてから、カマー・タージでの検査まで]]

## 腕輪の来歴

| 順 | 描かれること |
|---|---|
| 1 | 冒頭の語り（母イン・リーの声）。ある男が腕輪で神のような力と永遠の命を得て、自分の軍をテン・リングスと呼び、1000年にわたって力を追った。この男がウェンウー（トニー・レオン）で、腕輪はクレーターで見つけたとも、墓から盗んだとも言われている |
| 2 | ウェンウーはイン・リー（ファラ・チャン）と出会い、組織を離れ、腕輪を手放して家族と暮らす |
| 3 | イン・リーが殺され、ウェンウーは復讐のために腕輪をまたつけ、組織に戻る |
| 4 | 死ぬ前に、ウェンウーは腕輪をシャン・チー（シム・リウ）に託す |
| 5 | 最後の戦いで、シャン・チーは母の武術と腕輪の力を組み合わせて戦う |
| 6 | エンドクレジットの途中で、腕輪を持ったシャン・チーが、ウォンにカマー・タージへ連れて行かれる |

## エンドクレジットの途中（カマー・タージ）

ウォン（ベネディクト・ウォン）が、シャン・チーとケイティ（オークワフィナ）に、腕輪を持ってきたかと聞き、2人をカマー・タージへ連れて行きます。ウォンは『ドクター・ストレンジ』から出ている人物です。通信でブルース・バナーとキャロル・ダンヴァースが加わり、全員で腕輪を調べます。

| 調べたこと | 結果 |
|---|---|
| カマー・タージが持つ遺物の記録 | どれとも一致しない |
| ヴィブラニウム | 違う |
| チタウリの技術 | 違う（これまで見たエイリアンの技術とも違う） |
| 年代 | ウェンウーが使ってきた約1000年より、ずっと古い |
| シャン・チーが初めて腕輪を使ったとき | カマー・タージの側で、その力を感じ取っていた、とウォンが話す |
| 腕輪が出しているもの | メッセージを送っているらしいと分かる。どこへ、と聞かれたところで、キャロルが別の用件で抜け、バナーも去る |

バナーとキャロルが抜けたあと、ウォンは2人に、これからの人生は経験したことのないものになる、後戻りはない、と話します。

## 腕輪について、分かっていることと分かっていないこと

| 分かっていること | 分かっていないこと |
|---|---|
| 神のような力と永遠の命を与える（冒頭の語り） | ウェンウーが腕輪を手に入れた場所（クレーター説と、墓から盗んだ説が並ぶだけ） |
| 既知の遺物、ヴィブラニウム、チタウリの技術のどれとも違う | どこで、誰が作ったか |
| 約1000年よりずっと古い。ウェンウーが手に入れるより前からあった | ウェンウーの前に、誰が持っていたか |
| メッセージを送っているらしい | メッセージの宛先、メッセージの中身 |

## エンドクレジットのあと（シャーリン）

シャン・チーの妹シャーリン（メンガー・チャン）は、本編の終わりで、テン・リングスの組織を解体すると兄に話し、故郷に残ります。ところが、エンドクレジットのあとの場面では、シャーリンが新しいテン・リングスのリーダーになっています。解体はしていません。

ウェンウーはシャーリンに武術を習わせませんでしたが、シャーリンの組織では、女性も男性と並んで訓練を受けています。
