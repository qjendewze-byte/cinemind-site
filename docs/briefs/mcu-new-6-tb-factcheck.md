## 1. thunderbolts（サンダーボルツ*）

### 必ず直す

1. **excerpt の人数**
   - 原文: 「メンバーのうち5人は、『ブラック・ウィドウ』『アントマン＆ワスプ』とドラマ『ファルコン＆ウィンター・ソルジャー』のどれかに出ています。」
   - 問題: 7人のうちボブ以外の6人（エレーナ、レッド・ガーディアン、タスクマスター＝BW、ゴースト＝AMW、バッキー、ウォーカー＝FWS）が該当する。5人は誤り。
   - 修正: 「メンバー7人のうち6人は、…のどれかに出ています。ボブだけが新登場です。」
   - 出典: 記事自身の一覧表、公式キャラクターページ https://marvel.disney.co.jp/movie/thunderbolts

2. **ドラマ『ファルコン＆ウィンター・ソルジャー』の配信期間**
   - 原文: 「（2021年3月19日から4月13日）」
   - 問題: 最終話（第6話）の配信は **2021年4月23日**。日本語版Wikipediaの基礎情報の「4月13日」は、同じページのエピソード表（第6話 4月23日）と食い違う誤記。毎週金曜の配信で、3/19・3/26・4/2・4/9・4/16・4/23。
   - 修正: 「（2021年3月19日から4月23日）」
   - 出典: https://ja.wikipedia.org/wiki/ファルコン&ウィンター・ソルジャー （エピソード表）

3. **ヴァルの「初登場」**
   - 原文（足す作品の表、『ブラック・ウィドウ』の行）: 「ヴァルの初登場の場面もここ」
   - 問題: ヴァルが先に出たのはドラマ『ファルコン＆ウィンター・ソルジャー』第5話（2021年4月16日配信）。『ブラック・ウィドウ』（2021年7月8日日本公開）はその後。初登場ではない。
   - 修正: 「ヴァルのエンドクレジット後の場面もここ」
   - 出典: 同上エピソード表、https://ja.wikipedia.org/wiki/ブラック・ウィドウ_(映画)

4. **ヴァルの出どころ「2か所」**
   - 原文: 「出どころは2か所あります。」（ヴァレンティーナの節）、一覧表の「出ていた作品」もFWSとBWの2つだけ。
   - 問題: ヴァルは『ブラックパンサー／ワカンダ・フォーエバー』（2022）にも出ている（エヴェレット・ロスの元妻で上司として）。日本語版Wikipedia「サンダーボルツ*」の人物欄も「エヴェレット・ロスの元妻で上司」と書く。ブリーフ4-1も3作を挙げている。
   - 修正: 節は「主な出どころは2か所あります。」として、末尾に「『ブラックパンサー／ワカンダ・フォーエバー』（2022）にも出ています。」を1文足す。一覧表の欄にも「、『ブラックパンサー／ワカンダ・フォーエバー』」と「映画」を足す。足す作品の表には入れなくてよい。
   - 出典: https://ja.wikipedia.org/wiki/サンダーボルツ* （人物欄）、ブリーフ4-1（シネマトゥデイ https://www.cinematoday.jp/page/A0009532 ）

5. **題名「*」の節の公式表記**
   - 原文: 「公式サイトの表記は、副題つきで『サンダーボルツ*（*ニュー・アベンジャーズ）』です。」
   - 問題: 作品ページの題名は「サンダーボルツ*」だけ。「サンダーボルツ*（*ニュー・アベンジャーズ）」はキャラクター紹介ページのページ名と紹介文の書き出し（『サンダーボルツ*』（『*ニュー・アベンジャーズ』））。作品ページのあらすじには、新チーム名として「“*ニュー・アベンジャーズ”」とある。「副題つき」が公式の表記の全体のように読める。
   - 修正: 「公式サイトでは、作品ページのあらすじに『型破りなマーベルの新チーム“*ニュー・アベンジャーズ”』とあり、キャラクター紹介のページでは『サンダーボルツ*（*ニュー・アベンジャーズ）』と並べて書かれています。」と置き換える。続く「公式サイトの紹介文には、『*』の意味を説明した文はありません」「原題も Thunderbolts* で半角」はそのままでよい（確認済み）。
   - 出典: https://marvel.disney.co.jp/movie/thunderbolts 、https://marvel.disney.co.jp/movie/thunderbolts/character/bob （title・description）
   - 補足: 公式のあらすじ自体に「*ニュー・アベンジャーズ」があるので、この書き方は結末のネタバレにならない。噂・解釈・報道（THR Japan、リアルサウンドの説）は入っておらず、**節は公式の事実だけで書かれている**。この方針は維持する。「エンドクレジットでは The New Avengers」は結末に触れるので、入れるならネタバレ注意書きが要る（入れなくてよい）。

6. **上映時間**: 0章のAかBに合わせる（Aなら作品情報を126分に）。

## 2. captain4（キャプテン・アメリカ：ブレイブ・ニュー・ワールド）

### 必ず直す

1. **「襲う」**
   - 原文: 「キャプテン・アメリカを正式に襲うまでが描かれます。」
   - 問題: 「襲う」は「攻撃する」と読める。意味が逆に取られる。
   - 修正: 「キャプテン・アメリカを正式に受け継ぐまでが描かれます。」（「襲名する」でも可）

2. **『シビル・ウォー』に「大統領になった経緯」があるという記述**
   - 原文: 「本作のロスが大統領になった経緯と、サムとの関係の背景は、ここにあります。」
   - 問題: 『シビル・ウォー』のロスは国務長官で、大統領になる経緯は描かれていない（大統領になるのは本作までの間で、作中の描写はない）。ブリーフにもその根拠はない。
   - 修正: 「本作のロスとサムの因縁の背景は、ここにあります。」（大統領の経緯は削る）
   - 出典: https://ja.wikipedia.org/wiki/シビル・ウォー/キャプテン・アメリカ （ロスは国務長官）

3. **イザイアのスミソニアンの件**
   - 原文: 「ドラマの中で起きた出来事として、サムの働きかけでスミソニアン博物館に石碑が披露された、という話が本作の前提に出てきます。」
   - 問題: ドラマ最終話で描かれるのは、キャプテン・アメリカの展示の中に**イザイアのコーナー（展示）**が加わる場面。「石碑」と書いた日本語の出典はブリーフの jawiki-C4 の要約のみで、日本語版Wikipedia「ファルコン&ウィンター・ソルジャー」には石碑の記述がない。
   - 修正: 「ドラマの最終話では、サムの働きかけで、博物館のキャプテン・アメリカの展示にイザイアのコーナーが加わります。」
   - 出典: VG+ 第6話解説 https://virtualgorillaplus.com/drama/falcon-and-winter-soldier-ep6/ （「キャプテン・アメリカの展示がある博物館」「イザイア・ブラッドリーのコーナー」）

4. **公式おすすめ欄の「先頭」**
   - 原文: 「公式サイトのおすすめ作品欄は、先頭がドラマ『ファルコン＆ウィンター・ソルジャー』で、…」
   - 問題: 欄の先頭は本作自身（『キャプテン・アメリカ：ブレイブ・ニュー・ワールド』）。ドラマはその次。
   - 修正: 「公式サイトのおすすめ作品欄は、本作を除くと先頭がドラマ『ファルコン＆ウィンター・ソルジャー』で、…」。あわせて、欄全体（20作品）に『インクレディブル・ハルク』『エターナルズ』は入っていないことを確認したので、「この欄に『インクレディブル・ハルク』と『エターナルズ』は入っていません。」と1文足してよい（ハルク・エターナルズの節の根拠になる）。
   - 出典: https://marvel.disney.co.jp/movie/captain-america-bnw （2026-11-17取得。欄の全20作品）

### 直したほうがよい（小）

- 「3人が最初に出る場面の整理は、ハルクの記事にあります。」: hulk1 にあるのは、3人の出どころと、その後の作品での登場の表。「3人の出どころと、その後の出番の整理は、ハルクの記事にあります。」が正確。
