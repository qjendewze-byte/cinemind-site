# C. doomsday-prep.md・mcu-order.md との重なり

- **mcu-order.md**: 両作とも公開順の表に1行ずつ（160・168行目）と、F4が「ドゥームズデイ前に足す作品」に出るだけ。重なりはない。両記事の最後の `[[CARD:mcu-order]]` で足りる。
- **doomsday-prep.md**: 両記事とも「ドゥームズデイとの関係」の節が重なるが、doomsday-prep は「予習に何を見るか」、本2記事は「公式キャスト欄に本作の誰が載っているか」で、問いが違う。節を短く保ち、`[[CARD:doomsday-prep]]` で送る今の形でよい。DPW の A5（おすすめ欄14本）を削ると、予習寄りの記述がなくなり、さらに分かれる。
- **ずれは3つ**。上映時間（A6・B5）、ガンビットの言い方（「レジスタンスの一員」と「カサンドラと敵対する側」、A の直したほうがよい）、ドゥームの描写（B の直したほうがよい）。上映時間だけは必ずそろえる。
- **2記事どうし**: クリス・エヴァンスのジョニーが両方に出るが、DPW は「誰か」、F4 は「過去作との接点」として書いていて重複ではない。相互のカード（A7・B7）を、その行がある節の直後に置けば、読者が行き来しやすい。
