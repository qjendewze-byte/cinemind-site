3本とも、1文目で主の検索語には答えている（浅野＝ホーガン、ロキは生きている、最初の6人）。6章の型を1文ずつ見たが、メタな書き出し、「結論から言うと」、「XではなくY」、向き不向きの対句、決めゼリフの締め、評価語（圧巻・丁寧に描かれ・完成度 など）はない。thor2 は元がレビュー記事だが、感想・評価の言葉は残っていない。
不合格の原因は、(1) 2つ目の検索語（ホーガン 死亡／見なくていい／結成メンバー・アッセンブル）の答えが、title・meta・導入のどれかから抜けている、(2) thor2 の meta と「見なくていい？」の節に、本文と食い違う文・筋の通らない文がある、の2つ。

**3本に共通する「直したほうがよい」**
- 見出し「〜のその後」が3本すべてにある（ホーガンのその後／ロキのその後／ニューヨーク決戦のその後）。続けて読むと型に見える。各記事の案で別の見出しにした。
- meta が3本とも100字前後で、目安の120字に届いていない。下の案はどれも110〜120字前後にしてある。
- 文の長さは3本ともばらつきがあり（50字超が8〜24%）、4章の目安から大きく外れてはいない。ただ文末が全部「です／ます」で、「〜んです」が一度もない。答えの部分は言い切りでよいが、補足の文に1〜2か所混ぜると硬さが減る。
