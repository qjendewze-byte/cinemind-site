## 0. 先に読む（要点）

1. **需要はある。** 「マーベル 見る順番」「mcu 見る順番」の両方で「最低限」がサジェストに出る。最上位の派生は「ドラマ含む」「時系列」「ディズニープラス」「スパイダーマン」「公開順」「おすすめ」。「ドゥームズデイ までに見る{作品／べき作品／順番／もの}」も出る（2章）。
2. **上位の共通の弱点は、「最低限◯本」の理由が「重要だから厳選」で止まっていること。** 本数表記の食い違い、期限切れの配信・キャンペーン、時系列の並べ間違いも複数ある（3章）。cinemind は「Infinity War と Endgame の場面が、前作のどの出来事を前提に進むか」で線を引き、理由を作中の事実で書ける（5章）。
3. **日付は年だけ出す案を推す。** 日本公開日は、公式サイトの「劇場公開日」欄が全国公開日とずれている作品がある（『エンドゲーム』『キャプテン・マーベル』『ブラックパンサー』、4章）。日付を出すのは、順番が逆転する『ハルク』『アイアンマン』と『ドゥームズデイ』だけにすれば事故が減る。
4. **既存原稿の直すべき点は7章。** 特に「最短6本」にウルトロンがない、レビュー・感想という言い方が方針と合わない、記事数の記述が古い（9本→22本）、ドゥームズデイの節がない。
5. **最新: 『アベンジャーズ／ドゥームズデイ』は2026年12月18日（金）日米同時公開**（公式 https://marvel.disney.co.jp/movie/avengers-doomsday 、2026-11-14 確認）。公開5週間前。

## 5. 「最低限」の線引き案（根拠つき）

**線の引き方: 「IWとエンドゲームの場面が、前作のどの出来事を前提に進むか」を後ろから遡る。**「顔が分かれば足りる」ものは劇場でも分かる。「経緯が分からないと場面の意味が取れない」ものは削れない（doomsday-prep の整理と同じ軸）。

- **最低限5本（762分）**: アベンジャーズ → ウルトロン → シビル・ウォー → IW → エンドゲーム。理由は4-3の表。つまり「チーム結成」「ヴィジョンの誕生」「チーム分裂」「前編・後編」という作中のつながりだけで説明できる。
- 競合との違い: 同じ5本を出す記事（ネットオフ、シネマトゥデイの前半）は、理由が「厳選」「事実上2.5作目」で止まる。cinemind は各作の「次の作で前提になる出来事」を表にする。
- **外した作品について、見なくて困る場面を正直に書く**（見る順番.com が「感情移入は浅くなる」と認めている点は参考）。例: アイアンマンを外すと、エンドゲームの結末がトニーの物語として効かない。バトルロイヤルを外すと、IW冒頭のソー、ハルク、ロキの状態が分からない。
- **ドゥームズデイ向けの別線**: 5本＋直前3本（ブレイブ・ニュー・ワールド、サンダーボルツ*、F4）。公式15本とのちがいは、ドゥームズデイ予習記事（ID 637）へ送る。**637は承認待ちで未公開。公開前はリンク不可**（board 参照）。
- **決めるのは統括／記事作成役**: 本数を「5本＋足す順」にするか、「4本（Avengers・CW・IW・Endgame）」にするか。ウルトロン（ヴィジョンの誕生）を外すと、IWのワカンダの場面（ヴィジョンとワンダ）の意味が取れないため、5本を推す。
