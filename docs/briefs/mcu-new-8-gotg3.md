### 決定

**主題（title の問い）: 「ロケットの過去は？ハイ・エボリューショナリーとの関係（ネタバレあり）」。**
**副: ガモーラはなぜ別人になっているか。1節で足りる。**

根拠:
1. 「ロケット 過去」が4つの入力の形で出て、**一番ぶれない**。「敵」「ヴィラン」の答え（ハイ・エボリューショナリー）も、ロケットの過去の話で兼ねる。
2. 公式の紹介文が「ロケットの知られざる過去」を話の軸としている。事実だけで答えられ、**感想に流れない**。
3. 上位はテーマ（監督の発言）や感想で書く（5章）。**回想で何が起きたか、台詞の順に書いたもの、友達3匹の名前の決まり方を書いたものは取得した範囲では見つからなかった**。cinemindの強みにできる。
4. 副のガモーラは、公式が「別人」と書き、サジェストでも出るので、同じ記事に入れて損がない。

主題を「ラストの意味」にしなかった理由: 「ラスト」は、ロケットが船長になる、クイルの別れ、曲と、答えがばらける。ロケットの過去は、結末で「ロケットが何を選んだか」の前提になるので、結末はロケットの節に含めた。
