## 0. 先に読む注意

- slug は `spiderman-order`。**主題（titleの問い）は「スパイダーマンの映画の見る順番」**。「スパイダーマン 見る順番」で検索する日本人に、実写の全作品の順番と、どこまで見ればよいかの線引きを答える。
- style-guide 0章どおり、感想・評価・**配信（上位が厚く書く部分）**・声優・海外の点数は外した。配信状況は変動するので書かない（CLAUDE.md）。
- **噂・予想は入れない。** 『ビヨンド・ザ・スパイダーバース』の日本公開日、『ドゥームズデイ』へのスパイダーマンの出演などは、公式発表がなければ書かない。
- **日本公開日**は映画.com・日本語版Wikipedia・公式サイトで確認した。ただし**ライミ版3作・アメイジング版2作の公開日は、日本語版Wikipediaで取り、映画.comで確認できたのは1作目（2002-05-11、121分）とホームカミング以降**。残りの映画.com照合は事実確認役に頼む（9章）。
- 取得したページは作業用フォルダに置いたのみで、リポジトリには入れていない。
- 既存記事: `articles/mcu-order.md`（MCU全体）、`spiderman-homecoming.md`、`ffh.md`。`nwh`（別ブリーフ）は作成中。
