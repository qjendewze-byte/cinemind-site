## 直した箇所（原文 → 問題 → 修正 → 根拠）

1. **【要確認】バトルロイヤルと IW 冒頭**（最低限5本の「外れるもの」）
   - 原文: 「ソー、ハルク、ロキがなぜあの状態なのか、アスガルドがどうなったのかが分かりません。【要確認】…」
   - 確認結果: 事実として正しい。バトルロイヤルの結末でアスガルドは滅び、ソーとロキは民を乗せて地球へ向かう。エンドクレジットでその船に大型船（サノスのサンクチュアリII）が迫る。IW はその船がサノスに襲われる場面から始まり、ソー、ハルク、ロキ、ヘイムダルが乗っている。ルッソ監督も「ソーの話はバトルロイヤルの後から続く」と発言。
   - 修正: 「なぜ同じ船に乗っているのか」と具体化し、エンドクレジットの一文を足して【要確認】を削除。「足すなら」表のバトルロイヤル行も同じ事実で書き直した（ハルクがサカールにいた理由＝ウルトロン結末のクインジェット、も追記）。
   - 根拠: https://en.wikipedia.org/wiki/Thor:_Ragnarok ／ https://en.wikipedia.org/wiki/Avengers:_Infinity_War

2. **【要確認】GotG でのサノスの描かれ方**（「足すなら」表）
   - 原文: 「タイタンの場面でガーディアンズが出る。ガモーラとパワー・ストーン。【要確認】」（旧原稿の「サノスの目的とストーンの設定が具体的に語られる」は削除済みだった）
   - 確認結果: サノスはロナン、ネビュラとの1場面に本人が出る（ほかはホログラム）。ガモーラとネビュラはサノスの養女。ストーンの説明をするのはコレクターで、オーブの中身がパワー・ストーン。サノスの目的は作中で語られない。
   - 修正: 「ガモーラとネビュラはサノスの養女。オーブの中身がインフィニティ・ストーン（パワー・ストーン）だと分かる。サノス本人は短い場面に出るだけで、目的までは語られない」に。
   - 根拠: https://en.wikipedia.org/wiki/Guardians_of_the_Galaxy_(film)

3. **時系列の節「フェーズ4以降は時系列の並びが公式に示されていない」→ 誤り**
   - Disney+ のマーベル作品ページに「時系列」の並びがあり、マルチバース・サーガも含まれる（日本語版Wikipediaの年表ページもこれに従うと明記）。
   - 修正: 「別の宇宙や時間の流れが違う場所の話が増えて一列に並べにくいので、表にしていません」に変更（配信の案内はしない方針なので Disney+ 名は出さない）。
   - 根拠: https://ja.wikipedia.org/wiki/マーベル・シネマティック・ユニバースにおける年表

4. **『X-MEN』→『X-メン』（邦題の誤記）**: 2000年の1作目の邦題は『X-メン』。公式15本の報道表記も「X-メン」「X-MEN2」。本文の列挙と FAQ を修正。FAQ の理由も報道どおり「旧X-MENシリーズのキャストが再集結するため」に直した。
   - 根拠: https://www.cinematoday.jp/news/N0156368
