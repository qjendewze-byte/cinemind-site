# 引き継ぎ資料

2026年9月時点。クラウドセッションで進めた内容を、ローカルセッションが引き継ぐための資料。

---

## 1. サイトへの接続

環境変数 `WP_USER` / `WP_APP_PASSWORD` にログインIDとアプリケーションパスワードが入っている。

```bash
curl -u "$WP_USER:$WP_APP_PASSWORD" "https://cinemind.jp/wp-json/wp/v2/posts?status=draft"
```

**環境変数の値は出力・保存・コミットしないこと。**

- 権限: administrator（記事の作成・編集・公開・削除、画像アップロード、カテゴリー管理）
- テーマ: SWELL 2.15.0
- 主要プラグイン: SEO SIMPLE PACK、Pochipp、Code Snippets、Useful Blocks

### 導入済みのスニペット

Code Snippets に「SEO SIMPLE PACK の description を REST API に公開」を追加済み（有効）。

```php
add_action( 'init', function () {
	register_post_meta( 'post', 'ssp_meta_description', array(
		'type' => 'string', 'single' => true, 'show_in_rest' => true,
		'auth_callback' => function () { return current_user_can( 'edit_posts' ); },
	) );
} );
```

これにより `meta.ssp_meta_description` が REST API から読み書きできる。**このスニペットを無効化すると、メタディスクリプションが書き込めなくなる。**

## 5. SWELLのブログカード

内部リンクは、SWELLの関連記事ブロックを使う。アイキャッチ画像・タイトル・抜粋が出る。

```
<!-- wp:loos/post-link {"postId":"131"} /-->
```

`postId` は**文字列**で渡すこと。数値だと描画されない。

**見出しの中にリンクを埋めないこと。** 読者が押せることに気づかない。作品ごとの本文が終わった直後に、独立したブロックとして置く。

## 6. 変換スクリプト

`tools/md2gb.py` — Markdown原稿を WordPress のブロック形式に変換する。

```bash
python3 tools/md2gb.py articles/escapism-movies.md out.json
curl -u "$WP_USER:$WP_APP_PASSWORD" -X POST -H "Content-Type: application/json" \
  --data @out.json "https://cinemind.jp/wp-json/wp/v2/posts"
```

- 原稿冒頭の `title` / `slug` / `meta_description` を読んでJSONに含める
- 見出し・段落・表・箇条書きに対応
- `[[CARD:131]]` と書くとブログカードに変換される

## 7. SEOの調査結果

検索上位の顔ぶれを実際に確認した結果。

| 狙う検索語 | 上位の顔ぶれ | 勝てるか |
|---|---|---|
| 作品名＋感想・レビュー | Filmarks、映画.com | × 大手が独占 |
| 作品名＋あらすじ | 専門ブログ | × 厚い |
| シリーズ＋見る順番 | アニメイトタイムズ、マイナビ、cinemacafe、FILMAGA | × 大手が独占 |
| **気分・条件＋おすすめ** | **個人ブログ、Yahoo!知恵袋** | **○ 大手が不在** |

「90分以内 映画 おすすめ」「現実逃避したい時に見る映画」では、上位に映画.comもFilmarksもいない。個人ブログが取れている。

理由は構造的なもの。大手は作品データベースを自動でページ化するモデルなので、主観で選んで並べる記事を作らない。手間の割に量産できないため。

**この軸が唯一の突破口。** サイトの既存カテゴリー（現実逃避したい16件、前向きになりたい9件、家族と観たい8件、疲れた時5件）はまさにこの設計になっている。足りていなかったのは、そのカテゴリーに個別レビューしか入れず、まとめ記事を作らなかったこと。

### まとめ記事を作るときの注意

既存記事の在庫に合わせてラインナップを決めないこと。「現実逃避したい」16件のうち9件がMCU、2件がミッション：インポッシブルで、そのまま並べると同じシリーズばかりのリストになる。

読者が納得するラインナップを先に決め、レビューがない作品は新しく書く。

## 8. 未解決の課題

### 文体（最大の問題）

3通り試して、すべて却下されている。

| 試したもの | 却下理由 |
|---|---|
| 整った敬語 | 「ザAIが書いた文章」「効く映画、逃げ方は直訳っぽい」 |
| 既存記事に寄せた砕けた文体 | 「うざい」「偉そう」「独りよがり」 |
| 感想を排した事実だけの文体 | 「映画の裏話なんて読みたいと思うか」 |

却下された表現の詳細は `docs/style-guide.md` に記録済み。

**分かっていること**
- 既存24記事の文体（「ヤバい」「神」「号泣」）も却下されている
- 書き手が前に出るとうざくなる。テンションを演じても、分かっている側を演じてもダメ
- 読者が知らない人名から始める書き出しは通らない
- 「だからなに？」で終わる一文は通らない

**未解決**
サイト運営者が良いと思う文章の実例がまだない。ローカル環境なら外部ブログを読めるので、上位サイトの文章を実際に分析できる（クラウドでは後述の理由で不可能だった）。

### 読者が本当に求めている情報

「現実逃避したい映画」を探す人は、IMAXカメラの改造の話を求めていない。今夜どれを観るか決めたいだけ。

役に立つのはこういう情報。

- 疲れていても観られるか（頭を使うか）
- 途中で止めても大丈夫か
- 重い話か、軽い話か

制作の裏話に寄っていたのは、書き手が作品を観ておらず、それしか書ける材料がなかったため。**読者の役に立つからではない。**

### 観た人にしか書けない部分

サイト運営者は SF・アクション中心に観ている。504に入れた8作品（メッセージ、アバター、第9地区、レディ・プレイヤー1、インセプション、テネット、キングスマン、トップガン マーヴェリック）は視聴済み。

各作品1行の感想をもらえれば、それが他サイトとの決定的な差になる。何度か依頼したが、まだもらえていない。

## 9. クラウド環境の制約（ローカルでは解消するはず）

出口プロキシで通信先が制限されていた。

```
note.com:443       → 403 (policy denial)
eiga.com:443       → 403
filmarks.com:443   → 403
hatenablog.com:443 → 403
```

通ったのは ja.wikipedia.org、github.com、cinemind.jp のみ。

**このため、上位にいる個人ブログの文章を読めなかった。** 人間が書いた文章を参考にできないまま書いていたことが、AIっぽさが抜けない一因。

ローカル環境ならこの制限はないはずなので、**まず上位ブログの文章を実際に読んで文体を分析することを薦める。**
