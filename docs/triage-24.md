# 既存24記事の仕分け案（2026-09-27）

`docs/editorial-analysis.md` の分析と、今回の方針（気分×条件のまとめ記事をハブにする）をもとにした案。**実行はユーザーの承認後。** 公開済み記事にはまだ何もしていない。

## 結論

**今は削除もnoindexもしない。** 理由は2つ。

1. PVがほぼゼロの段階では、どの記事が検索で表示されているか（表示回数）のデータがない。データなしで消すと、表示されていた記事まで消すおそれがある
2. 24記事のうち15本は、今回作った／作っているまとめ記事からブログカードで参照される受け皿になる

代わりに、**まとめ記事を公開してから2〜3か月後に Search Console の表示回数を見て、表示ゼロの記事をnoindexにする**。
