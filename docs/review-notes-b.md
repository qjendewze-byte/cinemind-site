## 使用した「調べないと書けない事実」と出典

### トップガン マーヴェリック

1. **実機撮影**: F/A-18スーパーホーネットの後部座席に、専用開発の小型IMAX認証デジタルカメラを最大6台搭載(前方2台・後方4台)。操縦は現役海軍パイロットが担当。
   - 出典: https://av.watch.impress.co.jp/docs/news/1411268.html
   - 出典: https://www.cinemacafe.net/article/2022/04/22/78452.html
   - ※av.watchとcinematoday.jpは本セッションのネットワークプロキシでWebFetchがブロックされたため、WebSearchのスニペット経由で内容を確認した(URLは検索結果に基づく)。

2. **俳優の飛行訓練**: 出演俳優全員が3か月の飛行訓練カリキュラムを受講。セスナ→曲芸飛行→小型ジェット機と段階的に慣らす内容で、トム・クルーズ本人が設計。
   - 出典: https://theriver.jp/topgun-maverick-tom-stunts/(WebFetchはブロック。WebSearch要約で確認)

3. **公開延期の経緯**: 当初2019年7月12日予定→2020年6月24日→2020年12月23日→2021年7月2日→2021年11月19日と延期を重ね、2022年5月27日に世界公開。
   - 出典: https://ja.wikipedia.org/wiki/トップガン_マーヴェリック
   - 出典: https://eiga.com/news/20210413/6/
   - 出典: https://eiga.com/news/20210903/9/

### インセプション

1. **回転する廊下の撮影方法**: 英ベッドフォードシャーの倉庫に全長約30メートルの廊下セットを構築。鉄の輪7個の骨組みに55馬力モーター2基ずつを取り付けて回転させ、俳優は廊下と一緒に回りながら演技。
   - 出典: https://cgtracking.net/cg-news/映画『インセプション』の撮影風景/
   - 出典: https://jasonrodman.tokyo/inception-hallway-dream-fight/

2. **ラストの解釈についてのノーラン発言**: 「コマが倒れたかより、コブがもうコマを見届ける必要がなくなったことが重要」という趣旨の発言。マイケル・ケインへの「あなたが出ているシーンは全部現実」という回答の逸話。
   - 出典: https://theriver.jp/inception-last-nolan/
   - 出典: https://front-row.jp/_ct/17370858/

### TENET テネット

1. **逆行撮影の方法**: 同じシーンを2回撮影(通常演技と、逆行を実際に演じる演技)。逆回転撮影対応のIMAXフィルムカメラが存在しなかったため、IMAX社と共同でカメラとカートリッジを改造。
   - 出典: https://eiga.com/news/20200924/11/(WebFetchブロック、WebSearch要約で確認)
   - 出典: https://www.cinematoday.jp/news/N0119855(同上)

2. **IMAX撮影とVFX比率**: IMAXレーザー/GTシアターでは画角が最大1:1.43に拡大、通常スクリーン比で上下約40%映像が広がる。ICGマガジンの見積もりでVFXショットは300未満、ノーラン本人が「ラブコメ映画より少ないかもしれない」と発言。
   - 出典: https://www.cinematoday.jp/news/N0118787
   - ※「IMAXでの撮影比率」を明確なパーセンテージで示した一次情報は見つからなかった。英語ソース(nofilmschool.com等)でも「史上最多のIMAX映像」とはあるが正確な割合は非公開。そのため本文では画角拡大率とVFXショット数という、確認できた具体的な数字を代わりに使用した。

3. **音響批判とノーランの回答**: セリフが聞き取りにくいという苦情に対し「あえてそういうミックスにした。とても急進的なミックスだった」「サウンドに関して人々がこんなに保守的なのかとショックを受けた」と発言。別インタビューで「すべてを理解してもらおうとはしていない」とも発言。
   - 出典: https://www.cinematoday.jp/news/N0119840(WebFetchブロック、WebSearch要約で確認)
   - 出典: https://theriver.jp/tenet-not-meant-to-understand/

### メッセージ

1. **ヘプタポッドの文字デザイン**: プロダクションデザイナー、パトリス・ヴェルメットの妻でアーティストのマーティン・ベルトランが担当。理論物理学者スティーブン・ウルフラム(Mathematica開発者)の協力で100種類の文字パターンを作成。
   - 出典: https://news.livedoor.com/article/detail/13087828/(WebFetchブロック、WebSearch要約で確認)

2. **原作との違い**: 原作はテッド・チャン『あなたの人生の物語』。映画化にあたり英題は「Arrival」に変更(原題のままだと内容の一部が事前にわかってしまうため)。原作はルイーズ視点で現在と未来を行き来する構成、タイトルの「あなた」は娘アンナを指す。娘の死因の描写等が映画版と異なる。
   - 出典: https://ja.wikipedia.org/wiki/あなたの人生の物語
   - 出典: https://ja.wikipedia.org/wiki/メッセージ_(映画)

3. **言語学監修**: マギル大学の言語学者ジェシカ・クーン(Jessica Coon)が科学監修。専門はマヤ諸語の統語論。脚本にフィードバックを提供し、セット制作にも関与。彼女の研究室の本が劇中小道具として使用された。
   - 出典: https://www.mcgill.ca/newsroom/channels/news/mcgill-linguist-helped-upcoming-movie-arrival-263604
   - 出典: https://en.wikipedia.org/wiki/Jessica_Coon

## 確認できなかったこと・判断が必要なこと

- **テネットのIMAX撮影比率(%)**: 「作品全体の何%をIMAXフィルムで撮影したか」という明確な数値の一次情報が見つからなかった。英語圏のカメラマン情報でも「史上最多のIMAX映像を含む」という定性的な表現にとどまる。本文では画角拡大率(約40%)とVFXショット数(300未満)という、確認できた具体的な数字に差し替えた。**要判断**: より正確な一次情報(ノーランやホイテ・ヴァン・ホイテマのインタビュー全文など)が必要であれば追加調査する。
- **av.watch.impress.co.jp / www.cinematoday.jp / theriver.jp / news.livedoor.com / eiga.com**: 本セッションの環境ではネットワークプロキシによりWebFetchが直接アクセスをブロックされた(EGRESS_BLOCKED)。これらの記事内容はWebSearchが返した抜粋・要約を根拠に使用している。一次ソースへの直接アクセスができなかった点は明記しておく。**要判断**: 別環境での裏取りが可能であれば、原文を直接確認することを推奨する。
- **各記事のタイトル・見出し**: style-guide.mdの禁止表現(翻訳調、どの作品にも当てはまる評価語、曖昧な語尾)を避けるよう努めたが、最終チェックは人間の目でも確認いただきたい。
- **カテゴリー選定**: 既存カテゴリーから以下を選んだ。トップガン マーヴェリック＝アクション/洋画/疲れた時。インセプション＝SF/サスペンス/洋画。テネット＝SF/サスペンス/洋画。メッセージ＝SF/洋画/現実逃避したい。「サスペンス」は既存カテゴリー一覧に含まれていたため使用したが、既存24記事での実際の使用例は確認していない。**要判断**: 実際にWordPress側で「サスペンス」カテゴリーが存在するか、投稿時に確認が必要。
