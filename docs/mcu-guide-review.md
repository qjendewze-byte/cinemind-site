本セッションでも外部アクセスは大きく制限されており、**到達できた外部サイトは `ja.wikipedia.org` のみ**でした。
英語版Wikipedia、IMDb、eiga.com、cinematoday.jp、theriver.jp、marvel.disney.co.jp はいずれも接続が拒否され、出典記録に挙げられたURLを直接開いての裏取りはできていません。

そのため本レポートは、次の3種類を明確に分けて記載します。

- **確認済み**: ja.wikipedia.org の記述、または原稿内の数値計算・実際のHTTPアクセスで確かめたもの

## 2. 誤りの一覧（深刻度順）

### 【重大1】時系列順で「アイアンマン3」と「マイティ・ソー／ダーク・ワールド」が逆

- **原稿の記述**: 時系列順の表で、8番目「マイティ・ソー／ダーク・ワールド」、9番目「アイアンマン3」
- **正しい内容**: 「アイアンマン3」が先、「マイティ・ソー／ダーク・ワールド」があとです。順番を入れ替える必要があります。
- **根拠**: 日本語版Wikipedia「マーベル・シネマティック・ユニバースにおける年表」の「時系列の算出について」節に、次の記述があります。
  - 「『アイアンマン3』は、この年（2012年）のクリスマスに解決し、翌2013年にトニー・スタークは顛末をブルース・バナーに語る」
  - 「『マイティ・ソー/ダーク・ワールド』は2013年11月中に解決する（ジェーン・フォスターがソーの帰還を待つシーンでカレンダーが2013年11月になっている）」
  - 同記事の本編年表でも、2012年の項に『アイアンマン3』、2013年の項に『マイティ・ソー/ダーク・ワールド』が配置されています。
- **確認に使った出典URL**: `https://ja.wikipedia.org/wiki/マーベル・シネマティック・ユニバースにおける年表`
- **補足**: これはマーベル公式（Disney+）の時系列でも「アベンジャーズ → アイアンマン3 → ダーク・ワールド」の順とされている、定番の並びです。原稿が公開順（日本公開ではダーク・ワールドが2014年2月、アイアンマン3が2013年4月）と取り違えた可能性があります。なお日本公開順でもアイアンマン3のほうが先であり、どちらの基準でもこの並びは成立しません。

### 【重大2】時系列順で「ブラックパンサー」の位置が3つ後ろにずれている

- **原稿の記述**: 17番目「スパイダーマン：ホームカミング」、18番目「ドクター・ストレンジ」、19番目「ブラックパンサー」
- **正しい内容**: 「ブラックパンサー」は「ブラック・ウィドウ」の直後、「スパイダーマン：ホームカミング」より前に入ります。すなわち 15 シビル・ウォー → 16 ブラック・ウィドウ → **17 ブラックパンサー** → 18 ホームカミング → 19 ドクター・ストレンジ → 20 マイティ・ソー バトルロイヤル が正しい並びです。
- **根拠**: 同「年表」記事の2016年の項は、シビル・ウォー → ブラック・ウィドウ → **ブラックパンサー** → スパイダーマン：ホームカミング → ドクター・ストレンジ（決着）の順で出来事を並べています。
  - 『ブラックパンサー』はティ・チャカの死（シビル・ウォー劇中）を受けた直後の出来事として記述されています。
  - 『ホームカミング』は同記事の注記により「ホームカミング・ダンス・パーティが開催された2016年9月23日前後に発生し解決」（劇中チケットの "Friday September 23" 表記による）とされています。
- **確認に使った出典URL**: `https://ja.wikipedia.org/wiki/マーベル・シネマティック・ユニバースにおける年表`
- **補足**: 「ブラック・ウィドウは公開順と時系列順のズレの代表例」という原稿の主張自体は正しい（確認済み）のですが、同じ2016年の並びでブラックパンサーを誤配置しているため、記事の売りである時系列表の信頼性に関わります。

### 【重大3】未公開作品の邦題が誤り「アベンジャーズ：ダウンズデイ」

- **原稿の記述**: 「フェーズ6の『アベンジャーズ：ダウンズデイ』は2026年12月公開予定のため、この記事の対象外です」
- **正しい内容**: 正式な邦題は **『アベンジャーズ／ドゥームズデイ』** です。誤りは2か所あります。
  1. 「ダウンズデイ」→「**ドゥームズデイ**」（原題 *Avengers: Doomsday*）
  2. 区切り記号「：」→「**／**」（アベンジャーズシリーズは従来から「／」表記）
- **公開日**: 2026年12月18日（日米同時）で、「2026年12月公開予定」という原稿の記述自体は正しいです。
- **確認に使った出典URL**: `https://ja.wikipedia.org/wiki/アベンジャーズ/ドゥームズデイ` および `https://ja.wikipedia.org/wiki/マーベル・シネマティック・ユニバース`
- **補足**: 検索流入を狙う記事で最新作の題名を誤るのは、信頼性の面で影響が大きいと考えます。

### 【中2】「インフィニティ・サーガ24作品」という見出しが本文と矛盾

- **原稿の記述**: 本文「フェーズ1〜3は『インフィニティ・サーガ』と呼ばれ、サノスとの戦いを軸にした**23作品**でひとつの物語が完結します」／ 見出し「作中の時間軸順（**インフィニティ・サーガ、24作品**）」
- **正しい内容**: インフィニティ・サーガは23作品です（確認済み）。24番目に数えられている「ブラック・ウィドウ」はフェーズ4の作品であり、インフィニティ・サーガには含まれません。見出しの表現（例：「インフィニティ・サーガ23作品＋ブラック・ウィドウ」）を改める必要があります。
- **確認に使った出典URL**: `https://ja.wikipedia.org/wiki/マーベル・シネマティック・ユニバース`（インフィニティ・サーガの表が#1〜#23、フェーズ4は#24のブラック・ウィドウから始まる）
- **補足**: 執筆者の出典記録には「フェーズ1〜3の23本＋ブラック・ウィドウ」と正しく書かれており、本文への反映漏れと思われます。

### 【中3】フェーズ4以降の全14作品に「公開順と同じ」と付けている点

- **原稿の記述**: 時系列順の表で、25〜37番の備考がすべて「公開順と同じ」。本文も「フェーズ4以降はおおむね公開順と一致します」
- **確認できた事実**: 日本語版Wikipediaの年表では、フェーズ4以降の出来事は次の順に並んでおり、公開順とは一致しない箇所があります。
  - シャン・チー → ブラックパンサー／ワカンダ・フォーエバー（冒頭のティ・チャラ死去） → **スパイダーマン：ファー・フロム・ホーム** → スパイダーマン：ノー・ウェイ・ホーム → **エターナルズ** → ドクター・ストレンジ／MoM → ワカンダ・フォーエバー（本編） → ソー：ラブ＆サンダー → 以降は公開順と一致

- **指摘**: 本文は「公式に厳密な時系列順は示されていない」「おおむね一致」と慎重に書かれており、この姿勢自体は妥当です。しかし表の備考欄で14作品すべてに「公開順と同じ」と個別に断定すると、本文の慎重さと食い違います。備考欄を「公開順とほぼ同じ」等に改めるか、上記の相違点に触れることを薦めます。

- **原稿の記述**: 最短ルートの表で「ガーディアンズ・オブ・ギャラクシー｜後の黒幕**サノス**と、インフィニティ・ストーンの概念を**導入する**」

- **確認に使った出典URL**: `https://ja.wikipedia.org/wiki/サノス`（「実写映画では2012年の『アベンジャーズ』の最後にカメオ出演し、続いて2014年の『ガーディアンズ・オブ・ギャラクシー』に登場した」）

### 【低3】「『アベンジャーズ』でロキが登場して驚く」という例

### 【低4】「15番目と17番目の間に入ります」という循環した説明

- **原稿の記述**: 「時系列順で見る場合、この作品（ブラック・ウィドウ）は15番目と17番目の間に入ります」

## 4. 問題なしと確認できた項目

### 計算（すべて一致・確認済み）
表の上映時間を実際に合計して検算しました。**原稿内の数値どうしは、すべて完全に整合しています**（上映時間そのものの当否は【中1】のとおり別問題です）。

- フェーズ別合計6件すべて一致: 747分／758分／1,495分／976分／751分／260分
- 「〜時間〜分」への換算6件すべて一致: 12時間27分／12時間38分／24時間55分／16時間16分／12時間31分／4時間20分
- 総計 4,987分＝83時間7分 一致
- 4,987 ÷ 120 ＝ 41.56 → 「約41.6日」「42日ほど」いずれも正しい
- 1日1本なら38日前後 → 38作品なので正しい。平均上映時間131.2分は「平均2時間強」と整合
- 最短ルート6本の合計 868分＝14時間28分 一致
- 作品数: 6＋6＋11＋7＋6＋2＝38本。本文・各表・まとめのすべてで38本に統一されている
