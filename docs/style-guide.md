# cinemind.jp 記事の書き方

サイト運営者から却下された表現と、その理由をまとめたもの。**記事を書く前に必ず読むこと。**

---

## 1. 書き出し

読者が「読もう」と思う理由を、最初の3行で作る。

### やってはいけない

**説明から入る**

> 『ミッション：インポッシブル』(1996年)を検索すると、「話がわかりにくい」という検索が目立ちます。

→ 却下された。読者の用事に答えていない。

**読者が知らない固有名詞から入る**

> 試写室の途中で、ひとりの男が席を立ちました。俳優のグレッグ・モリスです。

→ 却下された。「グレッグ・モリスって誰？」となる。**読者が知っているのは主演俳優の名前くらい**だと考える。

**結論のない一文で締める**

> この場面だけは、みんな覚えています。でも「で、どういう話だったの」と答えられる人は、ぐっと減ります。

→ 却下された。「だからなに？」で終わっている。読者に得がない。

### 正しい形

読者が実際に持っている引っかかりから入り、**この記事を読むと何が得られるか**を示す。

> 何も手につかない夜ってありますよね。
>
> 仕事のことを考えたくないのにスマホを開いて、結局また仕事のことを考えている。そういう夜です。
>
> こういうときに映画を探すと「感動の名作」みたいなのが出てきますが、たぶん今はそういう気分じゃないと思います。欲しいのは、観ている間だけ全部忘れられるやつです。

---

## 2. 使ってはいけない言葉

### 翻訳調（最重要）

英語で考えた表現をそのまま日本語にしたもの。日本人は使わない。

| 使わない | 言い換え |
|---|---|
| 〜に効く映画 | 〜にハマる／〜に向いている／〜が刺さる |
| 逃げ方には3種類ある | 気分別／そのときの気分で変わる |
| 頭を別のもので埋める | 他のことを考えている余裕がなくなる |
| 世界ごと引っ越す | 違う世界に行く |
| 〜という一点では | 〜という意味では |
| 逃避先 | 行き先 |

### どの作品にも当てはまる評価語

既存24記事がこれで埋まっており、読まれない原因になっている。

- 丁寧に描かれ（ています）
- 胸を打つ／胸が熱くなる
- 完成度が高い／完成度が突出
- 〜という男／〜という存在
- 〜な一本です／〜な作品です（締めの決まり文句として）
- 心に深く響く
- 圧巻／必見／名作

### 曖昧な語尾

- 〜と思われます
- 〜かもしれません（推測を書くとき以外）
- 〜でしょう

---

## 3. 見出し

**読者が心の中で言っている言葉**をそのまま見出しにする。

| 使わない | 使う |
|---|---|
| 見どころ①②③ | （廃止。既存24記事中22記事がこれ） |
| 世界ごと引っ越す | とにかく違う世界に行きたいとき |
| 頭を空にする | 何も考えたくないとき |
| 難しい話で頭を埋める | 考えすぎて止まらないとき |

---

## 4. 文の長さ

1文が長いと翻訳調になる。短く区切る。

**悪い例**

> 教会での戦闘シーンは、音楽と暴力の組み合わせが完全に振り切れており、品はありませんが、そこがこの映画の魅力になっています。

**良い例**

> 教会のシーンは、音楽と暴力の組み合わせが完全にやりすぎています。品はありません。そこがいいんです。

---

## 5. 文体

敬語。ただし硬くしない。

- 「〜です」「〜ます」が基本
- 「〜んです」「〜と思います」「〜ですよね」を混ぜる
- 体言止めを使いすぎない
- 比喩は使わない

---

## 6. 観ていないものを観たように書かない

**これが既存24記事の最大の問題。**

書き手が作品を観ていない場合、視聴体験に基づく感想は書けない。書けるのは次の2つだけ。

1. 調べれば分かる事実（制作の裏側、数字、証言）
2. 構成の工夫

**観たふりをして感想を作らないこと。**

### 代わりに入れるもの

「調べないと書けない事実」を各作品に1つ以上。出典URLを記録すること。

例（『第9地区』）:

> 宇宙人のセリフには字幕が付きますが、人間側の会話の多くは俳優の即興です。だから台詞が整いすぎず、本当に撮影クルーが現場にいるように見えます。

---

## 7. 事実の扱い

- **記憶で書かない。** 公開年・上映時間・製作費・監督名は必ず WebSearch / WebFetch で確認する
- 配信サービスの情報は書かない（変動するため）
- 上映時間は**日本語版Wikipediaに統一する**（作品ごとに違う出典を使うと1分差が出る）
- 出典は記事本文には書かない。調査記録に残す

---

## 8. 内部リンク

見出しの中にリンクを埋めない。読者が気づかない。

SWELLのブログカードを使う。アイキャッチ画像と抜粋が出る。

```
<!-- wp:loos/post-link {"postId":"131"} /-->
```

作品セクションの本文が終わった直後に置く。

---

## 9. 記事の構成（個別レビューの場合）

1. 書き出し（読者の引っかかり、または具体的な場面から）
2. あらすじ（短く。ネタバレに触れるなら冒頭に注意書き）
3. 調べないと書けない事実
4. どういう人・どういう気分に向くか
5. 作品情報（表）
6. 関連記事のブログカード

まとめの章で教訓めいたことを書かない。

---

## 10. 付けるもの

記事原稿の冒頭に、次を必ず書く。

```
---
title: （32文字前後）
slug: （英数字）
meta_description: （120文字前後。検索結果に出る）
excerpt: （60〜80文字。ブログカードに出る。meta_descriptionと同じにしない）
categories: （既存カテゴリーから選ぶ）
---
```
