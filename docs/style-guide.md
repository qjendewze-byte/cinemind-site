# cinemind.jp 記事の書き方

**記事を書く前に必ず読むこと。** 根拠は `docs/reference-blogs.md`（上位個人ブログの分析、2026-09-27）。

---

## 0. 読者は日本人

**読むのは日本の映画ファン。** 海外でしか意味のない情報（韓国やアメリカだけの公開・リメイク、Rotten Tomatoes等の海外批評サイトの点数など）は入れない。検索語がサジェストに出ていても、日本の読者の役に立つかを先に確かめる。（2026-09-28、韓国版リメイクと海外批評サイトの点数の節を入れて却下された）

## 0-2. いちばん大事なこと

これまで3回、語尾やテンションを変えて却下された。**問題は語尾ではなかった。** 上位の個人ブログと比べると、差は次の4つ。

1. **画面に映っているものを具体的に書く**（「アクションがすごい」ではなく、どう動くか）
2. **「ないもの」をはっきり書く**（派手なアクションはない、画面は汚い、途中で説明はない）
3. **評価ではなく好みとして言う**（「傑作」ではなく「好き」。格付けしない）
4. **文の長さを揃えない**（短い断片と、つなげた長い文を混ぜる）

---

## 1. 感想は書かない

cinemind.jp は感想サイトではない（2026-09-28 ユーザー決定）。感想・体験・「観てどうだったか」は書かず、【メモ待ち】欄も置かない。

書くのは、確認できる事実と、それを読者の疑問に合わせて整理したもの。「好みとして言う」（0-2章の3）は、選んだ理由を書くときの言い方として使う。

## 2. 書き出し

**前置きの段落は書かない。**（2026-10-05 ユーザー指摘）「〜分かりにくいんですよね」「〜気になった人向けです」「観ていない人のほうが多いと思います」のような、読者に同意するだけ・前提を言うだけの導入はいらない。見出しの直後から本題（答えや表）に入る。


### 形

1. 検索した人の事情に**同意する**。説明しない。同じ側に立つ
2. **どう選んだか**と**偏り**を先に言う。「SF・アクションをよく観ているので、そっちに寄っています」
3. 何が載っているか（上映時間つき、気分別 など）

偏りを先に言うと、押しつけがましさが消える。サイト運営者がSF・アクション中心に観ていることは、隠すより書いたほうがいい。

### やってはいけない

- **説明から入る**（「『〇〇』を検索すると、〜という検索が目立ちます」）→ 読者の用事に答えていない
- **読者が知らない固有名詞から入る**（脇役の俳優名、スタッフ名）→ 読者が知っているのは主演の名前くらい
- **「だからなに？」で終わる一文** → 読者に得がない

---

## 3. 作品ごとの書き方

順番は固定しない。入れるものは次のとおり。

- **どういう話か**: 2〜4文。「〜という話です」「〜って感じの話です」程度の軽さでいい
- **観るとどういう体験か**: 画面に映るもの、動き、音。抽象語（世界観・緊張感・映像美）で済ませない
- **ないもの**: 期待を調整できる情報。読者の役に立つのはここ
- **注意点**: 長さ、ネタバレを踏みやすい場所（Wikipediaのあらすじは結末まで書いてある など）、前作が必要か
- **反応**: メモがあるときだけ

### 締め

**決めゼリフで締めない。** 前の下書きは段落のほとんどが決めゼリフで終わっていた。

| 使わない | 代わり |
|---|---|
| 行き先としては、この14本で一番遠いところです | （書かずに終わる） |
| 誰とも喋りたくない日にどうぞ | 「〜が好きな人はぜひ」程度か、何も書かない |
| 〜を教えてくれる映画です | （書かない） |
| 〜な一本です／作品です | （書かない） |

---

## 4. 文のリズム

**短く区切りすぎない。** 前の下書き（504）は文の中央値22字、50字を超える文が1%しかなく、全文がほぼ同じ長さだった。これも機械っぽく見える。

目安（手本のブログの実測値）:

- 文の中央値は25字前後
- **50字を超える文が15〜20%ある**
- 短い断片（「体をちょっと動かすだけ。」）と、「〜んですけど、」でつなぐ長い文を混ぜる
- 括弧で補足を入れていい（「（ここが好きです）」）

**悪い例**（長さが揃い、全部言い切っている）

> 舞台はゲームの中。知っているキャラクターが次から次に出てきます。「あ、あれだ」と言っているうちに終わります。考える暇がありません。

**方向性**（長さが不揃いで、具体的なものが入っている）

> 舞台はほぼ全部ゲームの中なんですけど、知っているキャラクターが背景に普通に映り込んでくるので、話を追いながらそっちも探すことになります。考える暇はあまりないです。

---

## 5. 文体

- **です・ます基調。** ただし「〜んです」「〜ですよね」「〜なんですけど」を混ぜる
- 反応の部分は常体の短い断片も可（「なんでそれなの。」）
- 体言止めを続けない。対句（AよりB、AだけどB）を続けない
- 比喩は使わない
- 格付けの言葉を使わない（傑作・名作・最高傑作・完成度・圧巻・必見・神）
- 好みは「好きです」「苦手でした」で言う

---

## 6. 使ってはいけない言葉

### 翻訳調（最重要）

| 使わない | 言い換え |
|---|---|
| 〜に効く映画 | 〜にハマる／〜に向いている |
| 逃げ方には3種類ある | 気分別／そのときの気分で変わる |
| 頭を別のもので埋める | 他のことを考えている余裕がなくなる |
| 世界ごと引っ越す | 違う世界に行く |
| 〜という一点では | 〜という意味では |
| 逃避先 | 行き先 |

### どの作品にも当てはまる評価語

- 丁寧に描かれ（ています）
- 胸を打つ／胸が熱くなる／心に深く響く
- 完成度が高い
- 〜という男／〜という存在
- 普遍的なテーマ
- 圧巻／必見／名作

### 検証で何度も「AIっぽい」と指摘された型（2026-09-27 追記）

どれも1回なら人間も書くが、記事の中や記事どうしで繰り返すと一目でテンプレートだと分かる。

| 型 | 例 | 代わり |
|---|---|---|
| メタな書き出し | 「『〇〇』で検索している人は〜」「〜が気になっている人、多いと思います」 | 読者の疑問にそのまま同意して、すぐ答える |
| 宣言文 | 「結論から言うと」「先に答えを書くと」「この記事では〜を整理しました」「事実だけを並べます」 | 削る。答えを書けば宣言は要らない |
| 向き不向きの対句 | 「〜な人には向きません。逆に、〜な人には合います」 | 事実を1つ書いて止める（「151分あって、途中で話が止まらない」） |
| 「XではなくY」 | 「単なる小ネタではなく、意図した演出です」 | 削る |
| 物語の導入の定型 | 「〜を繰り返している男がいます」「ある家族が暮らしています」 | 「〜という話です」か、場面から入る |
| 締めの否定短文の連続 | 「品はないです。」「いい子たちの話ではないです。」が続く | 1記事1回まで |
| 見出しの上映時間を本文で繰り返す | 「93分なので、12本で一番短いです」 | 一覧表か見出しのどちらかだけ |
| 検索語をそのまま貼ったタイトル | 「キングスマン 順番｜〜」 | 「キングスマンを観る順番は？〜」 |
| 全作品が同じ段落構成 | あらすじ→豆知識→メモ、が12本続く | 1段落だけの作品、長く脱線する作品を混ぜる |

**作品のまとめ記事は、選んだ作品と書き出しの宣言が矛盾していないかを必ず確認する。**（例:「重たい作品は避けたい」と書いてインターステラーを入れる）。観ていない人が書いたと一番ばれやすいのはここ。

### 曖昧な語尾

- 〜と思われます
- 〜でしょう
- 〜かもしれません（推測を書くとき以外）

---

## 7. 見出し

**読者が心の中で言っている言葉**をそのまま見出しにする。

| 使わない | 使う |
|---|---|
| 見どころ①②③ | （廃止） |
| 世界ごと引っ越す | とにかく違う世界に行きたいとき |
| 頭を空にする | 何も考えたくないとき |

作品の見出しには上映時間を入れる（例: `### 第9地区（111分）`）。

---

## 8. 事実の扱い

### 入れる事実の種類

**裏話は入れない。**「映画の裏話なんて読みたいと思うか」で却下済み。

入れるのは、**観る前に知っておくと選びやすくなる事実**だけ。

| 入れる | 入れない |
|---|---|
| 登場人物がほぼ1人、舞台が車の中だけ | 撮影に使ったカメラの改造 |
| 前作を観ていないと分からない | 監督がこの作品を撮った経緯 |
| 字幕を追うのが忙しい／英語以外の言語が多い | 俳優の役作りの話 |
| 終盤まで説明がない、2回観る前提の作り | 製作費・興行収入 |

### 確認のしかた

- **記憶で書かない。** 公開年・上映時間・監督名は WebSearch / WebFetch で確認する
- 上映時間は**日本語版Wikipediaに統一する**（出典を混ぜると1分差が出る）
- 配信サービスの情報は書かない（変動するため）
- 出典は本文に書かない。調査記録に残す

---

## 9. 内部リンク

見出しの中にリンクを埋めない。読者が気づかない。

SWELLのブログカードを、作品セクションの本文が終わった直後に置く。

```
<!-- wp:loos/post-link {"postId":"131"} /-->
```

## 10. 原稿の頭書き

```
---
title: （32文字前後）
slug: （英数字）
meta_description: （120文字前後。検索結果に出る）
excerpt: （60〜80文字。ブログカードに出る。meta_descriptionと同じにしない）
categories: （既存カテゴリーから選ぶ）
---
```
